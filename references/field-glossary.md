## 一、信号处理术语

| 术语 | 一句话定义 | 生活化比喻 | 故障诊断场景例子 |
|---|---|---|---|
| FFT（快速傅里叶变换） | 把时域信号变成频域信号，看有哪些频率成分 | 把一段合唱拆解成"每个歌手唱多大声" | 轴承振动信号做FFT后，故障频率处会出现峰值 |
| VMD（变分模态分解） | 把信号自动分成K个窄带模态（IMF） | 把一杯混合果汁自动分离成几杯纯果汁 | 电磁阀振动信号分解成4个模态，每个对应不同故障频率带 |
| 小波变换（Wavelet Transform） | 同时看信号的时间和频率信息 | 用不同倍数的放大镜看信号，既看整体又看细节 | 轴承冲击故障在时频图上呈现周期性条纹 |
| EMD（经验模态分解） | 把信号分解成若干本征模态函数 | 像剥洋葱一样一层层剥出不同频率的成分 | 齿轮箱振动信号EMD后提取故障特征 |
| 包络谱（Envelope Spectrum） | 对信号做希尔伯特变换后取频谱，提取调制频率 | 把收音机的调幅信号解调，听到里面的音频 | 轴承外圈故障的包络谱在故障频率处有明显谱线 |
| 采样频率（Sampling Rate） | 每秒记录多少个数据点 | 每秒给运动物体拍多少张照片 | 12kHz采样=每秒录12000个振动数据点 |
| 信噪比（SNR） | 信号功率与噪声功率的比值 | 说话声音和背景噪音的比例 | 工业现场电磁阀信号SNR低，故障特征被噪声淹没 |

**数字例子模板（2点FFT）**：
先说清关系：FFT 是"快速算出 DFT 结果"的算法，N=2 时直接按 DFT 定义算就等于 FFT。
DFT 定义式 $X[k]=\sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}$，取信号 x=[1,-1]，N=2：
- k=0：X[0] = 1·e^0 + (-1)·e^0 = 1 + (-1) = 0
- k=1：X[1] = 1·e^0 + (-1)·e^(-jπ) = 1·1 + (-1)·(-1) = 1 + 1 = 2
- 幅值谱 |X[0]|=0、|X[1]|=2 → 这个信号里没有直流成分，只有最高频成分（每个采样点都换号）

再取 x=[1,1]：X[0] = 1+1 = 2，X[1] = 1 + 1·(-1) = 0 → 只有直流成分，没有高频成分。
**关键点**：第 n 个采样点乘的是 $e^{-j2\pi kn/N}$，指数里的 n 必须跟着数据点的下标走，不能张冠李戴。

## 二、机器学习与深度学习术语

| 术语 | 一句话定义 | 生活化比喻 | 故障诊断场景例子 |
|---|---|---|---|
| CNN（卷积神经网络） | 用小窗口滑动扫描提取局部特征 | 用放大镜在照片上扫来扫去找特征 | 用1D CNN扫描振动信号，提取局部故障模式 |
| 注意力机制（Attention） | 给不同部分学不同权重，重要的多关注 | 人看照片自动盯着人脸忽略背景 | SENet给5个信号通道分配不同重要度权重 |
| Transformer | 基于自注意力的序列建模网络 | 读文章时每个词都参考全文其他词 | 用Transformer处理振动信号序列，捕捉长距离依赖 |
| 对比学习（Contrastive Learning） | 让相似样本特征靠近、不相似样本远离 | 把同一种水果放一堆，不同水果分开放 | 同一故障的信号特征在隐空间聚类，不同故障分开 |
| 批归一化（Batch Normalization, BN） | 把每层输出标准化，稳定训练 | 每次考试前把分数归一化，方便比较 | 训练故障分类网络时BN加速收敛 |
| Dropout | 训练时随机丢弃部分神经元，防止过拟合 | 考试前随机不复习某些题，逼自己全面掌握 | 故障诊断模型加Dropout减少过拟合 |
| 激活函数（Activation, ReLU） | 把负数变0，引入非线性 | 低于阈值的信号直接忽略 | CNN每层后接ReLU，只保留正向响应 |
| 残差连接（Residual Connection） | 把输入直接加到输出上，让深层网络好训练 | 抄近路，别让信息翻山越岭丢掉 | ResNet式结构让深层诊断网络不退化 |
| 池化（Pooling） | 在小窗口里取最大/平均，压缩尺寸 | 把一段话压缩成一句摘要 | 最大池化保留振动信号里最强的冲击响应 |

**数字例子模板（1D卷积，信号视角）**：
输入 x=[1,2,3,-1]，卷积核 k=[1,0,-1]，步长1、无padding：
- 第1个输出位置（覆盖 x[0..2]=[1,2,3]）：1×1 + 2×0 + 3×(-1) = 1 - 3 = **-2**
- 第2个输出位置（覆盖 x[1..3]=[2,3,-1]）：2×1 + 3×0 + (-1)×(-1) = 2 + 1 = **3**
- 输出 [-2, 3]。含义：这个核在算"当前点与前面第二个点的差"，信号突变的地方响应大 → 这就是1D CNN能抓住故障冲击的原因

**数字例子模板（2D卷积，时频图/图像视角）**：
输入 3×3 矩阵 [[1,2,3],[4,5,6],[7,8,9]]，核为 2×2 全1（求和核），步长1、无padding → 输出 2×2：
- 左上角（覆盖子块 [[1,2],[4,5]]）：1+2+4+5 = **12**
- 右上角（覆盖 [[2,3],[5,6]]）：2+3+5+6 = **16**
- 左下角（覆盖 [[4,5],[7,8]]）：4+5+7+8 = **24**
- 右下角（覆盖 [[5,6],[8,9]]）：5+6+8+9 = **28**
- 若把核换成边缘检测核 [[1,-1],[-1,1]]，本例四个输出全是 0——因为输入是均匀递增的，局部没有突变。**平坦处响应0、突变处响应大**，这就是卷积核能当"特征探测器"的原因

## 三、迁移学习与域自适应术语

| 术语 | 一句话定义 | 生活化比喻 | 故障诊断场景例子 |
|---|---|---|---|
| 域自适应（Domain Adaptation, DA） | 让源域训练的模型在目标域也能用 | 在南方练的车，到北方下雪天也能开 | 实验室台架数据训练，工业现场也能诊断 |
| 源域/目标域（Source/Target Domain） | 训练数据所在域 / 要应用的新域 | 课本知识（源）→ 实际工作（目标） | 源域=标准工况数据，目标域=变工况/现场数据 |
| 域偏移（Domain Shift） | 源域和目标域数据分布不一致 | 课本例题和考试题题型不一样 | 实验室数据干净，现场数据噪声大、工况变 |
| DANN（对抗域自适应） | 用对抗训练对齐域特征，梯度反转层让特征提取器学不到域差异 | 故意把导航反过来，让模型分不清东南西北 | 特征提取器+域判别器对抗，对齐源域目标域特征 |
| MMD（最大均值差异） | 度量两个分布在再生核希尔伯特空间中的距离 | 比较两堆水果的平均大小、颜色差异 | 最小化源域和目标域特征的MMD距离实现对齐 |
| 负迁移（Negative Transfer） | 源域知识反而干扰目标域性能 | 学了自行车反而不会骑三轮车 | 工况差异太大时强行对齐导致诊断精度下降 |
| 半监督学习（Semi-supervised Learning） | 用少量标注+大量无标注数据训练 | 老师批改几篇作文，剩下的自己对照学 | 目标域只有5个标注样本+大量无标注信号 |
| 伪标签（Pseudo-label） | 模型给无标注数据打的标签，再用来训练 | 学生自己做题对答案，错题再学 | 目标域无标注信号用模型打伪标签，加入训练 |

**数字例子模板（MMD 的均值差直觉）**：
⚠️ 这是**简化版直觉**，不是严格的 MMD：真实 MMD 要先用核函数把样本映射到高维空间，再比较两个分布的均值嵌入；这里只用"两组特征均值的欧氏距离"演示"越小越像"。
- 源域特征均值 [1,2]，目标域特征均值 [4,5]：距离 = √((4-1)²+(5-2)²) = √18 ≈ **4.24**
- 对齐后目标域均值变成 [1.5,2.5]：距离 = √((1.5-1)²+(2.5-2)²) = √0.5 ≈ **0.71**
- 结论：数值从 4.24 降到 0.71，说明两个域的特征分布更接近了 → 讲解时必须补一句"严格定义见论文式(X)"

## 四、耦合故障诊断术语

| 术语 | 一句话定义 | 生活化比喻 | 故障诊断场景例子 |
|---|---|---|---|
| 耦合故障（Coupled Faults） | 多种故障同时发生，特征相互混叠 | 感冒+咳嗽+发烧同时来，症状混在一起 | 阀芯卡滞+弹簧退化同时发生，振动信号特征重叠 |
| 故障解耦（Fault Decoupling） | 从混合信号中分离出各故障的独立特征 | 把合唱里每个歌手的声音单独分离出来 | 从电磁阀混合振动中分离出阀芯故障和弹簧故障特征 |
| 多标签分类（Multi-label Classification） | 一个样本同时属于多个类别 | 一道菜可以同时是"辣的""荤菜""川菜" | 一段信号同时标注"阀芯卡滞"和"密封泄漏" |
| 盲源分离（Blind Source Separation, BSS） | 不知道源信号的情况下从混合信号中分离 | 不知道菜谱，从成品菜里分离出每种调料 | ICA从混合振动中分离独立故障源 |
| 特征解耦表征（Disentangled Representation） | 学习各故障独立的、互不干扰的特征表示 | 给每种水果建独立档案，不混在一起 | 双分支网络分别学故障特异性特征和共享特征 |
| 正交约束（Orthogonality Constraint） | 约束不同故障特征在隐空间正交（不相关） | 让不同科目的成绩互不影响 | 阀芯故障特征和弹簧故障特征在隐空间正交分离 |

## 五、边缘计算与轻量化术语

| 术语 | 一句话定义 | 生活化比喻 | 故障诊断场景例子 |
|---|---|---|---|
| 边缘计算（Edge Computing） | 把计算放到靠近数据源的设备上 | 在工厂现场直接看病，不用送大医院 | 电磁阀旁边的边缘网关直接做诊断，不上传云端 |
| 模型剪枝（Pruning） | 去掉网络中不重要的权重/通道 | 把书里不重要的章节撕掉，变薄 | 剪掉CNN中不重要的卷积通道，减少参数量 |
| 量化（Quantization） | 把浮点权重变成整数（如INT8），减少内存和计算 | 把精确到克的秤改成精确到两，更快 | 模型从FP32量化到INT8，推理速度快4倍 |
| 知识蒸馏（Knowledge Distillation） | 用大模型（教师）教小模型（学生） | 教授把知识浓缩成笔记给学生 | 大诊断模型教小模型，小模型保留大部分精度 |
| 推理时延（Inference Latency） | 模型从输入到输出结果的时间 | 医生从看到病人到给出诊断的时间 | 边缘端推理时延<10ms满足实时预警 |
| 参数量（Parameters） | 模型中可训练参数的总数 | 一本书有多少个字 | 轻量CNN参数量约10万，大模型可能几千万 |

## 九、机器学习基础概念（第2、4节讲损失与训练时必用）

| 术语 | 一句话定义 | 生活化比喻 | 数字例子 |
|---|---|---|---|
| 损失函数（Loss Function） | 衡量"预测和真值差多远"的分数，越小越好 | 考试扣分，扣得越少越好 | 见下方 MSE / 交叉熵模板 |
| MSE（均方误差） | 把每个误差平方后求平均 | 估重量，估错1斤和估错2斤，惩罚差4倍 | 真值 [1,5]、预测 [1,3] → ((1-1)²+(5-3)²)/2 = 4/2 = **2** |
| 交叉熵（Cross-Entropy） | 分类任务里惩罚"给正确答案的概率太低" | 押注押错了要狠罚，押对且押重了几乎不罚 | 见下方模板 |
| Softmax | 把一串分数变成加起来等于1的概率 | 把三个人的得分换成"中奖概率" | 见下方模板 |
| 学习率（Learning Rate, η） | 每次更新参数走多大一步 | 下山时每步迈多大：太大滚下去，太小学得慢 | η=0.1 比 η=0.001 快10倍，但可能震荡不收敛 |
| 优化器（Optimizer） | 决定"怎么根据梯度更新参数"的规则 | 下山的走法：SGD是直着走，Adam是带惯性和自适应步长 | SGD 只看当前坡度；Adam 还记住历史坡度方向 |
| 梯度（Gradient）/反向传播 | 梯度=参数往哪调、调多少；反向传播=从后往前算出每个参数的梯度 | 找到"哪个旋钮往哪拧能少扣分"，再一层层往回追责 | f(w)=w² 在 w=3 处梯度=2w=6 |
| 过拟合（Overfitting） | 训练集表现好、新数据表现差 | 把练习册答案背下来了，换套题就不会 | 训练准确率99%、测试准确率60% = 过拟合 |
| 欠拟合（Underfitting） | 训练集都学不好，模型太弱 | 连练习册都没学会 | 训练、测试准确率都只有60% |
| 正则化（Regularization, L1/L2） | 给"参数太大"加惩罚，防止过拟合 | 不许把话说得太满太绝对 | 损失 = 原损失 + λ·Σw² |
| Epoch / Batch | Epoch=全部数据过一遍；Batch=一次喂给模型的一小批样本 | 背单词：一遍书=1个epoch，一次背20个=1个batch | 1000个样本、batch=100 → 1个epoch有10次参数更新 |

**数字例子模板（Softmax）**：
模型输出分数（logits）z=[1,2,3]：
- 先取指数：e¹≈2.718，e²≈7.389，e³≈20.086，合计 30.193
- 再归一化：2.718/30.193 ≈ **0.09**，7.389/30.193 ≈ **0.24**，20.086/30.193 ≈ **0.67**
- 三个数加起来等于 1 → 模型认为"第3类"的概率最大（0.67）

**数字例子模板（交叉熵）**：
真实类别是第3类，模型预测概率 [0.09, 0.24, 0.67]：
- 交叉熵 = -ln(0.67) ≈ **0.40**
- 如果模型更自信：[0.01, 0.04, 0.95] → -ln(0.95) ≈ **0.05**（损失更小）
- 如果模型看错了：[0.67, 0.24, 0.09]（第3类只给0.09）→ -ln(0.09) ≈ **2.41**（损失急剧变大）
- 含义：交叉熵只盯着"正确答案那一项"，给它的概率越低，惩罚越狠（对数会放大）

## 十、评价指标（第5节必用）

先给混淆矩阵的四个格子（以"故障"为正类）：
- TP（真正例）：真故障、判成故障
- FP（假正例）：正常、误判成故障（虚警）
- FN（假负例）：真故障、漏判成正常（漏报）
- TN（真负例）：正常、判成正常

| 指标 | 公式 | 一句话含义 | 什么时候更要看它 |
|---|---|---|---|
| 准确率（Accuracy） | (TP+TN)/(TP+FP+FN+TN) | 判对的占总数的比例 | 类别均衡时够用 |
| 精确率（Precision） | TP/(TP+FP) | 报出来的故障里有多少是真故障 | 怕虚警（误停机）时最看重 |
| 召回率（Recall） | TP/(TP+FN) | 真故障里有多少被找出来了 | 怕漏报（漏检事故）时最看重 |
| F1 分数 | 2·P·R/(P+R) | 精确率和召回率的折中 | 两类错误都怕，类别不均衡 |

**数字例子模板（用混淆矩阵手算）**：
某次诊断共20个样本：TP=6、FP=2、FN=4、TN=8
- 准确率 = (6+8)/20 = 14/20 = **0.70**
- 精确率 = 6/(6+2) = 6/8 = **0.75**（报出8个故障，6个是真的）
- 召回率 = 6/(6+4) = 6/10 = **0.60**（10个真故障，只找出6个）
- F1 = 2×0.75×0.60/(0.75+0.60) = 0.90/1.35 ≈ **0.667**
- 含义：准确率0.70看着还行，但召回率只有0.60 = **10个故障漏掉4个**，工业诊断里往往不可接受 → 讲解时要把这层含义点出来

## 十一、数学符号与希腊字母速查表（讲公式时随手查）

### 常用记号

| 符号 | 读法 | 含义 | 极小数字例子 |
|---|---|---|---|
| $\sum$ | 西格玛（求和号） | 把一堆数加起来 | $\sum_{i=1}^{3} i^2 = 1+4+9 = 14$ |
| $\prod$ | 派（求积号） | 把一堆数乘起来 | $\prod_{i=1}^{3} i = 1\times2\times3 = 6$ |
| $\int$ | 积分号 | 连续版的"求和"，把曲线下的面积累加 | $\int_0^2 x\,dx = 2$ |
| $\partial$ | 偏导（round d） | 只对其中一个变量求斜率，其他当常数 | f(a,b)=a²b：∂f/∂a=2ab，a=2,b=3 → 12 |
| $\nabla$ | 纳布拉（梯度） | 把所有偏导装成一个向量，指向上升最快方向 | f(w)=w²：∇f=2w，w=3 → 6 |
| $\mathbb{E}[\cdot]$ | 期望 | 平均意义上的取值 | X 等可能取 1,2,3 → E[X]=(1+2+3)/3=2 |
| $\arg\max$ / $\arg\min$ | 取最大/最小处 | 不返回最大值，返回"最大值在哪个位置/哪个参数" | argmax([0.1,0.7,0.2])=第2个 |
| $\|\cdot\|$ | 范数（双竖线） | 向量的长度 | ‖[3,4]‖ = √(9+16) = 5 |
| $\odot$ | 逐元素乘（哈达玛积） | 对应位置相乘，不是矩阵乘法 | [1,2]⊙[3,4] = [3,8] |
| $\otimes$ | 张量积/卷积记号 | 两路特征组合成更大特征（具体含义看论文定义） | 论文里出现时必须按其定义解释 |
| $(\cdot)^{\top}$ | 转置 | 行列互换 | [[1,2],[3,4]]ᵀ = [[1,3],[2,4]] |
| $\hat{y}$ | y-hat | 模型的预测值（和真值 y 区分） | 真值 y=1，预测 ŷ=0.7 |
| $\in$ / $\forall$ | 属于 / 对所有 | 元素属于集合 / 对每一个都成立 | x ∈ {正常, 故障} |
| $\propto$ | 正比于 | 只差一个常数倍 | y ∝ 1/x：x 翻倍，y 减半 |
| $\approx$ | 约等于 | 四舍五入后的近似 | √2 ≈ 1.41 |
| $\lvert\cdot\rvert$ | 绝对值/模 | 丢掉负号；复数则取长度 | \|-3\| = 3 |
