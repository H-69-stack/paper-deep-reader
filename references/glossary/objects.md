# 术语分册：研究对象与故障机理

> 用户的研究对象是**带电摩擦副**：导电滚环 RCC、电机、液压电磁阀、滑环、轴承。这册讲"这些部件长什么样、坏的时候信号什么样"——精讲里做比喻与迁移讨论时从这里取素材。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 故障时的典型信号表现。

| 术语 | 一句话定义 | 生活化比喻 | 故障时的典型信号表现 |
|---|---|---|---|
| 带电摩擦副 | 既传导电流又承受相对摩擦运动的接触副 | 一边擦火一边通电的"旋转插头" | 电与摩擦耦合：磨损加剧电蚀，电蚀又加速磨损 |
| 导电滚环（RCC） | 用滚环+电刷实现旋转件与静止件间导电的部件 | 给旋转的摄像头上电的"滑动的电刷" | 接触电阻波动、电弧烧蚀、磨屑堆积 → 电压波动+振动 |
| 滑环（Slip Ring） | 靠滑动接触传电/传信号的环形部件 | 老式电话的旋转接头 | 环面沟槽、刷握松动、绝缘下降 |
| 电刷（Brush） | 与环面滑动接触的导电块 | 铅笔芯在转盘上摩擦取电 | 磨损变短、弹簧压力不足 → 打火、火花噪声 |
| 接触电阻（Contact Resistance） | 接触界面处的等效电阻 | 两个金属面只有几个点真正碰到 | 上升 → 局部发热；跳变 → 电弧与信号毛刺 |
| 摩擦磨损（Friction & Wear） | 相对运动导致的材料损失 | 鞋底越走越薄 | 磨粒进入间隙、配合面粗糙度变化 → 振动能量缓升 |
| 磨粒（Debris） | 摩擦产生的金属/碳粉颗粒 | 铅笔屑 | 堆积造成卡滞与短路，也污染润滑 |
| 电弧 / 打火（Arcing） | 接触分离瞬间空气击穿放电 | 冬天脱毛衣的噼啪 | 高频宽带冲击，是电噪声的典型来源 |
| 电蚀（Electrical Erosion） | 电弧烧蚀接触表面形成凹坑 | 被电火花点出小坑的金属面 | 凹坑加剧机械冲击与接触电阻波动 |
| 温升（Temperature Rise） | 电流与摩擦共同引起的温度上升 | 一直摩擦的手心发热 | 接触电阻增大 → 局部热点，可作早期征兆 |
| 电流信号（Motor Current Signature） | 从驱动电流里读故障特征 | 从"耗电多少"看"干活顺不顺" | MCSA 可诊断断条、偏心、负载异常 |
| 电机（Motor） | 电能转机械能的核心驱动件 | 设备的心脏 | 电流/振动/温度三路信号联合诊断 |
| 定子 / 转子 | 静止的电磁部分 / 旋转的电磁部分 | 外套与内芯 | 定子绕组短路、转子断条各有特征频率 |
| 轴承（Bearing） | 支撑旋转、降低摩擦的滚动或滑动部件 | 轮子里的滚珠 | 早期冲击→包络谱特征频率；后期宽带噪声抬升 |
| 内圈 / 外圈 / 滚动体 | 轴承的三个关键零件 | 跑道的内侧、外侧、跑者本身 | 各自有 BPFI / BPFO / BSF 特征频率 |
| 点蚀 / 剥落（Spalling） | 滚道表面出现小坑或片状脱落 | 跑道上的坑洼 | 冲击序列出现，包络谱特征频率及谐波清晰 |
| 保持架（Cage） | 固定滚动体间距的骨架 | 让跑者保持队形的栏杆 | 保持架故障频率 FTF，常伴随调制 |
| 液压电磁阀 | 用电信号控制液压油路的开关/方向/压力 | 油路的红绿灯 + 闸门 | 卡滞、内泄漏、线圈老化 → 压力响应慢、抖动 |
| 阀芯 / 阀套 | 阀内相对滑动配合的柱塞与套筒 | 注射器活塞与筒壁 | 磨损增大间隙 → 内泄漏；污染卡滞 → 动作不到位 |
| 线圈（Solenoid Coil） | 通电产生磁力驱动阀芯的绕组 | 电磁铁 | 匝间短路/老化 → 电流曲线畸变、吸合延迟 |
| 卡滞（Stiction / Sticking） | 阀芯因污染或磨损卡住不动 | 抽屉滑轨卡住 | 指令与响应不同步，出现滞环与台阶 |
| 内泄漏（Internal Leakage） | 油从高压腔漏到低压腔 | 水龙头关不严还滴水 | 保压能力下降，压力曲线缓慢下滑 |
| 空化 / 气蚀（Cavitation） | 局部压力低于饱和压时油液汽化再溃灭 | 开水壶里的气泡炸裂 | 高频宽带噪声，损伤阀口与密封 |
| 密封件老化 | O 圈/密封圈硬化、开裂导致渗漏 | 旧橡皮筋失去弹性 | 外泄漏、压力不稳，温度升高加速老化 |
| 换向阀 / 比例阀 / 伺服阀 | 按开关、按比例、按闭环精确控制流量方向 | 开关、旋钮、精密调节器 | 控制精度不同，故障诊断的难点也不同 |
| 转频（Shaft Frequency） | 轴每秒钟转多少圈对应的频率 | 心跳频率 | 1× 转频异常 → 不平衡；2× → 不对中 |
| 边带（Sideband） | 主频两侧间隔等于某调制频率的成分 | 主音旁边陪着的和声 | 边带间距常指向调制源（如保持架、齿轮） |
| 共振（Resonance） | 结构在某频率上振动被放大的现象 | 秋千越推越高 | 轴承故障冲击会激发结构共振，包络分析就抓它 |
| 松动（Looseness） | 紧固失效导致配合面活动 | 螺丝松了的桌腿 | 频谱出现 1× 的多次谐波，时域有削顶 |
| 不平衡 / 不对中 | 质量偏心 / 两轴轴线不重合 | 洗衣机甩干晃 / 两节水管没接直 | 1× 幅值大 / 2×、轴向振动大 |
| 工况（转速、负载、油温） | 设备运行的外部条件 | 天气 | 工况变化会掩盖或伪造故障特征，必须记录 |
| 传感器安装位置 | 振动/温度传感器贴在哪 | 听诊器放的位置 | 位置选错，最好的算法也救不回来 |

## 数字例子模板（轴承特征频率的粗略估计）

设轴转频 fr = 25 Hz（1500 rpm），滚珠数 Z = 9，接触角近似为 0，节径比 d/D ≈ 0.2。
BPFO ≈ (Z/2)·fr·(1 − d/D) = 4.5 × 25 × 0.8 = 90 Hz。
BPFI ≈ (Z/2)·fr·(1 + d/D) = 4.5 × 25 × 1.2 = 135 Hz。
**读法**：外圈故障在 90 Hz 附近出现及其谐波，内圈故障在 135 Hz 附近——**这两个数才是包络谱里要找的东西**，不是随便一个峰。
