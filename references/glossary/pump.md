# 术语分册：泵

> 泵把机械能变成流体能。诊断泵比诊断轴承难，因为**流体本身也在振动**：汽蚀、脉动、喘振都会在同一个频谱里留下痕迹，和机械故障混在一起。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 信号里怎么体现。

| 术语 | 一句话定义 | 生活化比喻 | 信号里怎么体现 |
|---|---|---|---|
| 泵（Pump） | 把机械能转换为流体压力能/动能的机械 | 给水流加压的"心脏" | 振动、压力脉动、流量、电流多路信号 |
| 离心泵 | 靠叶轮旋转把流体甩出去 | 甩干机 | 流量大、扬程中等，特性曲线平缓 |
| 容积泵 | 靠容积变化挤出流体（齿轮/柱塞/叶片泵） | 注射器推药 | 流量稳定、压力高，脉动明显 |
| 齿轮泵 | 靠两齿轮啮合挤出油液 | 两个咬合的齿轮挤牙膏 | 齿轮磨损 → 内泄漏与流量下降 |
| 柱塞泵 | 靠柱塞往复改变容积 | 打气筒 | 高压场合主力，故障多在配流盘与柱塞副 |
| 叶片泵 | 靠叶片在转子槽内滑动 | 旋转的百叶窗 | 定子内曲线磨损是典型故障 |
| 流量 Q | 单位时间输送的流体体积 | 水管的出水量 | 与磨损、内泄漏直接相关 |
| 扬程 H | 单位重量流体获得的能量，换算成液柱高度 | 能把水举多高 | 离心泵的 H–Q 曲线是诊断基准 |
| H–Q 特性曲线 | 扬程随流量变化的曲线 | 泵的"力气随开口大小变化" | 曲线整体下移 → 磨损或转速下降 |
| 轴功率 / 效率 | 输入机械功率 / 有效输出功率占比 | 耗多少电、干多少活 | 效率下降常先于流量明显下降 |
| 比转速 | 表征泵型式的无量纲参数 | 泵的"体型身份证" | 决定曲线形状，不能跨型式套用经验 |
| 叶轮 | 泵的旋转做功部件 | 风扇叶 | 叶片磨损/断裂 → 通过频率与不平衡 |
| 叶片通过频率 BPF | 叶轮每转经过固定点的次数对应的频率 `BPF = z·fr` | 每转吹过几次风 | 频谱主峰之一，叶片故障在它两侧长边带 |
| 导叶 / 蜗壳 | 引导流体流出叶轮的静止件 | 出风口的导流罩 | 与叶轮间隙变化会产生强烈窄带噪声 |
| 汽蚀（Cavitation） | 局部压力低于饱和蒸气压时汽化再溃灭 | 开水壶里的气泡炸裂 | 宽带高频噪声 + 随机冲击，流量与扬程同时下降 |
| 汽蚀余量 NPSH | 保证泵入口不汽化所需的最小压力余量 | 喝水不能把杯子倒空到吸管进空气 | NPSH_available < NPSH_required → 必然汽蚀 |
| 气缚 / 抽空 | 泵内吸入空气导致无法建立压力 | 吸管漏气吸不上来 | 压力剧烈波动、电流下降、流量骤降 |
| 干运转 | 无液状态下运行导致摩擦副烧损 | 干烧锅 | 温度急升、密封与轴承短时损坏 |
| 密封环间隙 | 叶轮与泵壳之间的环形间隙 | 风扇叶尖与外壳的缝 | 间隙磨大 → 内泄漏增大、效率下降 |
| 内泄漏 | 高压侧向低压侧的漏流（容积泵称"滑移"） | 水龙头关不严 | 流量随压力升高而明显下降是典型特征 |
| 容积效率 | 实际流量与理论流量之比 | 打气筒漏气后还能打进去多少 | 下降说明间隙磨损或密封失效 |
| 流量脉动 | 容积泵固有的周期性流量波动 | 手压井一下一下出水 | 脉动频率 = 转速 × 柱塞数，是压力脉动的根源 |
| 压力脉动 | 出口压力的周期性波动 | 水管里的"水锤" | 频谱出现轴频及其倍频，可激励管路共振 |
| 喘振（Surge） | 流量过小时流体周期性倒流 | 人喘不上气 | 低频大幅压力振荡，常伴随剧烈振动 |
| 轴向力 | 叶轮前后压差产生的轴向推力 | 被水往前顶 | 靠平衡孔/平衡盘抵消，失效则推力轴承过载 |
| 平衡孔 / 平衡盘 | 平衡轴向力的结构 | 给压力开个泄口 | 堵塞或磨损 → 轴向力失衡、推力轴承温升 |
| 机械密封 | 靠两个端面贴合阻止泄漏的密封 | 两片磨平的瓷片贴紧 | 端面磨损 → 外泄漏、温升、甚至冒烟 |
| 填料密封 | 用填料压紧在轴上的传统密封 | 布条塞缝 | 允许微漏，压得过紧会发热磨损 |
| 轴承与泵轴 | 支撑转子并传递转矩 | 泵的"关节" | 轴承故障特征频率可直接套用 `bearing.md` |
| 联轴器不对中 | 泵轴与电机轴轴线不重合 | 两节水管没接直 | 2× 转频突出、轴向振动大 |
| 油温与黏度 | 工作油温度与其黏稠度 | 蜂蜜冷天更稠 | 影响内泄漏与容积效率，必须与温度一起看 |
| 泵的故障频率账 | 转频、叶片通过频率、脉动频率、轴承特征频率 | 各零件的"嗓门" | 先算清四个数，再逐个在谱里核对 |

## 数字例子：一台离心泵的叶片通过频率

设电机 4 极、50 Hz，转差率 2%，叶轮 7 个叶片。

- 同步转速：$n_s = 60f/p = 60 \times 50/2 = 1500$ rpm
- 实际转速：$n = 1500 \times 0.98 = 1470$ rpm → 转频 $f_r = 24.5$ Hz
- 叶片通过频率：$BPF = z f_r = 7 \times 24.5 = 171.5$ Hz

**读法**：171.5 Hz 及其 2×（343 Hz）在频谱里通常是"正常也很大"的成分，不能当成故障。真正要看的是：**BPF 两侧是否出现转频间隔的边带**（说明单个叶片损伤）、**BPF 幅值是否随流量剧烈变化**（说明间隙或汽蚀）。

## 数字例子：容积效率掉了多少

某齿轮泵理论流量 $Q_t = 20$ L/min。出口压力 5 MPa 时实测 $Q = 18$ L/min，10 MPa 时实测 $Q = 15$ L/min。

- 5 MPa：$\eta_v = 18/20 = 0.90$
- 10 MPa：$\eta_v = 15/20 = 0.75$

**读法**：同一台泵，压力翻倍容积效率掉 15 个百分点，说明内泄漏随压差显著增大——**间隙磨损的典型指纹**。如果两个压力下效率都差不多低，那更像是吸油不畅或气缚，而不是磨损。
