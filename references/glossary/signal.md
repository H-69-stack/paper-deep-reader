# 术语分册：信号处理

> PHM 的第一道工序永远是"从传感器电压里挖出能说明问题的东西"。先读索引选册，这一册讲采样、变换、滤波、分解、统计指标。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 在故障诊断里的用法。数字例子是模板，用真实数据时要换成论文里的数。

| 术语 | 一句话定义 | 生活化比喻 | 在故障诊断里的用法 |
|---|---|---|---|
| 采样（Sampling） | 每隔固定时间把连续信号取一个数，变成离散序列 | 用秒表每隔一秒拍一张照片，把"连续动作"变成"连环画" | 采集卡按 10 kHz 采振动信号，采样率定错会直接丢掉故障特征 |
| 采样定理（Nyquist） | 采样率必须大于信号最高频率的 2 倍，否则高频会"冒充"低频 | 电影里车轮倒转，就是拍得太慢造成的假象 | 轴承高频共振在 8 kHz 以上，采样率至少 20 kHz 才不漏 |
| 混叠（Aliasing） | 高于 Nyquist 频率的分量被折到低频，伪装成别的频率 | 车轮倒转：真实在正转，看着在倒转 | 混叠后故障特征频率会跑偏，诊断模型学到错的特征 |
| 量化（Quantization） | 把连续幅值切成有限个刻度 | 只有厘米刻度的尺子去量毫米 | 16 位 ADC 比 8 位能分辨更小的早期冲击 |
| 采样频率与采样点数 | 采样率 fs 决定"多快"，点数 N 决定"多长" | fs 是快门速度，N 是录像时长 | 分辨率 Δf = fs/N：N 太小，两个相近故障频率分不开 |
| 时域波形（Time Domain） | 信号随时间的原始起伏 | 心电图那条弯曲线 | 早期故障在时域只表现为很淡的冲击，肉眼难辨 |
| 傅里叶变换（Fourier Transform） | 把信号拆成不同频率的正弦波之和 | 把一段和弦拆成"哪几个音在响、各多响" | 轴承故障在频谱上出现特征频率及其谐波 |
| 频谱（Spectrum） | 各频率成分的幅值分布图（横轴频率、纵轴幅值） | 把和弦拆开后画成"音高-音量"柱状图 | 看 1×、2×、3× 转频与边带判断不平衡、不对中、松动 |
| 功率谱密度（PSD） | 能量在频率上的分布，单位是"功率/Hz" | 一条街每个路段的平均车流量 | 比原始频谱更稳，适合做健康指标的趋势输入 |
| 包络分析（Envelope Analysis） | 先取信号包络，再对包络做频谱 | 只听"鼓点"的密集程度，不管鼓声本身多高 | 轴承早期故障的冲击会调制高频共振，包络谱里特征频率特别干净 |
| 希尔伯特变换（Hilbert Transform） | 由实信号构造解析信号，从而得到瞬时幅值/相位 | 给波形的"外壳"描一条边 | 包络谱的第一步，也用来算瞬时转速 |
| 解调（Demodulation） | 把"载在高频上的信息"取下来 | 从广播电台的高频载波里取出人声 | 轴承/齿轮故障诊断的核心手段：带通 + 包络 + 谱 |
| 带通滤波（Band-pass） | 只保留某频段的成分 | 只留下"中音区"的乐器声 | 选共振频带做包络，频带选错就什么也看不到 |
| 低通 / 高通滤波 | 低通留慢变化，高通留快变化 | 低通 = 只看趋势；高通 = 只看突变 | 高通去趋势，低通去高频噪声 |
| 陷波滤波（Notch） | 精确掐掉某个频率 | 把邻居家固定频率的嗡嗡声关掉 | 掐掉 50/60 Hz 工频干扰及其谐波 |
| 短时傅里叶变换（STFT） | 分小段做傅里叶，得到"时间-频率"图 | 把录像切成小段，每段分别看有哪些音 | 看故障冲击随时间的演变，比单张频谱信息多 |
| 小波变换（Wavelet Transform） | 用可伸缩的"小波"在不同尺度上看信号 | 用大小不同的放大镜分段看同一张照片 | 冲击类故障的利器：既看"何时"又看"哪个频段" |
| 连续小波 / 尺度图（CWT, Scalogram） | 连续尺度的小波系数铺成二维图 | 一副"时间 × 尺度"的热力图 | 常被转成图片喂给 CNN（GADF/CWT 图谱诊断） |
| 离散小波变换（DWT） | 按 2 的幂做多分辨率分解，得到近似与细节系数 | 把图像一层层做马赛克 | 做降噪与特征压缩，取某层细节系数当特征 |
| 经验模态分解（EMD） | 把信号自适应拆成若干本征模态函数 IMF | 把一锅杂烩汤按密度自动分层 | 分解后对某层 IMF 做包络谱，抑制噪声 |
| 集合经验模态分解（EEMD） | EMD 加白噪声多次平均，缓解模态混叠 | 多摇几次再取平均，结果更稳 | 实测信号噪声大时优先用 EEMD 而非 EMD |
| 变分模态分解（VMD） | 预设分量个数，用变分优化求解各模态 | 事先定好"分几层"，再按最优方式分层 | 比 EMD 更抗混叠，常做轴承早期故障的预处理 |
| 倒谱（Cepstrum） | 对"频谱的对数"再做一次傅里叶 | 对"音高分布"再统计一次，找周期性 | 分离边带，定位齿轮/轴承的调制周期 |
| 循环平稳分析（Cyclostationary） | 统计量随时间周期变化的信号分析方法 | 一个每到整点就响一次的闹钟 | 变转速、强噪声下的轴承诊断很吃这套 |
| 阶次分析（Order Analysis） | 按"每转"而不是"每秒"重新采样 | 把不同车速下的录音都换算成"每圈的声音" | 变转速工况下让故障特征频率不漂移 |
| 信噪比（SNR） | 有用信号功率与噪声功率之比（dB） | 在嘈杂车间里听清一个人说话有多难 | 报"低 SNR 下仍达 xx% 准确率"是在强调鲁棒性 |
| 峭度（Kurtosis） | 四阶统计量，衡量"尖不尖"，高斯噪声为 3 | 一段音乐里"突然的鼓点"有多突出 | 早期冲击故障峭度升高，常做健康指标或选频带依据 |
| 峰值因子 / 脉冲因子 / 波形因子 / 裕度因子 | 峰值、均值、有效值、方根幅值之间的几种比值 | 同一条波形用不同尺子量"尖"的程度 | 传统时域特征集，现在常作为深度模型的输入通道 |
| 均方根（RMS） | 信号幅值的有效值，反映能量 | 一段路的平均颠簸程度 | 磨损类故障的经典趋势指标，随退化单调上升 |
| 去趋势（Detrending） | 去掉信号缓慢漂移的基线 | 把斜坡上的楼梯"放平"再看台阶 | 温漂、零点漂移会毁掉趋势指标，必须先去除 |
| 归一化（z-score / min-max） | 把不同量纲的数据缩放同一尺度 | 把身高体重换算成统一评分 | 多传感器融合前必备，否则量纲大的通道会主导 |
| 数据增强（信号侧） | 加噪、平移、缩放、加窗重采样来造新样本 | 把同一张照片翻转、调亮，扩充训练集 | 故障样本少时的标配；但增强方式要符合物理意义 |
| 加窗（Windowing） | 分帧时乘汉宁/汉明窗减少频谱泄漏 | 给每段录音两端做淡入淡出 | STFT/FFT 前不做窗，边带会糊成一片 |

## 数字例子模板（2 点 FFT）

x = [1, −1]（两个采样点）。
X(0) = 1 + (−1) = 0；X(1) = 1 − (−1) = 2。所以频谱是 X = [0, 2]：直流分量为 0，Nyquist 频率分量幅值为 2。
换成 x = [1, 1]：X = [2, 0]，全是直流，没有波动。
**读法**：2 点 FFT 就是"同相加"和"反相减"，一个数变大另一个变小，说明信号在"变化"。
