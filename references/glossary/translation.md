# 术语分册：领域翻译表与比喻库

> 论文往往来自 NLP、CV、推荐系统这些"离车间很远"的领域。这册的作用是**桥**：把别人的术语翻译成故障诊断的语言，再用一个能映射的比喻说清。
> 原则：比喻必须可映射回原概念，不能只是"听起来像"。迁移讨论放第7节，讲清代价。

## 一、领域翻译表（论文领域 → 故障诊断）

| 论文里的说法 | 在故障诊断里对应什么 | 迁移时的注意点 |
|---|---|---|
| 图像 / 像素 / 通道 | 时频图 / 时间采样点 / 传感器通道 | 图像的平移不变性在振动信号上不总成立（相位有物理意义） |
| 词 / 句子 / 文档 | 采样点 / 一个窗口 / 一次完整试验 | 语言的语法结构 vs 信号的物理周期，不能直接类比 |
| 掩码语言建模（MLM） | 随机遮蔽信号片段让模型预测 | 信号被遮蔽后仍要满足物理连续性，随机遮挡可能造出不可能的信号 |
| 数据增强（裁剪/翻转） | 时间平移、加噪、幅值缩放、重采样 | 翻转图像没问题，翻转振动信号等于反转时间，物理上不一定有意义 |
| 目标检测框 | 故障发生的时间段 / 故障位置定位 | 工业上更关心"何时开始"，框的粒度要重新定义 |
| 语义分割 | 逐采样点/逐时刻的状态标注 | 标注成本极高，通常只有窗口级标签 |
| 对比学习的正负样本对 | 同工况不同时刻 / 不同故障类型 | 正样本对必须"同一物理状态"，否则学到的是工况而非故障 |
| 提示（Prompt） | 给模型的任务描述与示例 | 信号不能直接当提示文本，通常要转成统计描述或图谱 |
| 检索（Retrieval） | 检索历史工单/维修手册/相似案例 | 案例库的标注质量决定上限 |
| 推荐系统的用户-物品 | 设备-工况 / 传感器-故障模式 | 交互矩阵在诊断里通常是稀疏且不平衡的 |
| 强化学习的动作与奖励 | 维修动作与成本/停机损失 | 奖励设计错会学到"什么都不修"这种最省事策略 |
| 图神经网络的节点与边 | 传感器 / 部件 / 它们之间的物理连接 | 边权最好来自物理耦合强度，而不是随便设 1 |
| 联邦学习的客户端 | 各台设备 / 各工厂 | 数据不能出厂是真实约束，通信成本与异构性要算 |
| 蒸馏的教师-学生 | 大模型-边缘小模型 | 教师模型在目标域的准确率是学生的天花板 |

## 二、带电摩擦副 / 电磁阀比喻库（做"通俗理解"时直接取用）

| 概念 | 可用的比喻 | 映射要点 |
|---|---|---|
| 耦合故障 | 两根缠在一起的绳子，拉一根另一根也动 | 强调"单故障假设会失效"，不是简单叠加 |
| 接触电阻波动 | 两个金属面只有几个凸点真正碰到 | 接触面积→电阻→发热，链条要讲全 |
| 电弧 | 冬天脱毛衣的噼啪 | 分离瞬间击穿，宽带高频 |
| 电蚀凹坑 | 被电火花点出小坑的金属面 | 凹坑变成新的冲击源，形成恶性循环 |
| 内泄漏 | 关不严的水龙头还在滴水 | 压力保不住，缓慢下滑 |
| 卡滞 | 抽屉滑轨卡住 | 指令到了、动作没到，出现滞环 |
| 密封老化 | 失去弹性的旧橡皮筋 | 硬化→渗漏→温升→更快老化 |
| 轴承早期故障 | 鞋里进了一粒沙，每走一步硌一下 | 周期性冲击，是包络谱的物理来源 |
| 轴承后期故障 | 沙粒变成石子，整条路都在响 | 宽带噪声抬升，特征频率反而被淹没 |
| 共振 | 秋千越推越高 | 故障冲击"正好推在"结构固有频率上 |
| 不平衡 / 不对中 | 洗衣机甩干晃 / 两节水管没接直 | 1× 与 2× 的区分依据 |
| 域偏移 | 在南方学的驾驶经验拿到北方雪地 | 不是模型笨，是分布变了 |
| 小样本 | 只看过三张片子就要会看诊 | 需要先验/迁移/生成，而不是硬训 |
| RUL 预测 | 手机电量还能用几小时 | 曲线外推 + 阈值交点 |
| 健康指标 | 体检报告的综合评分 | 要单调、要可解释 |
| 数据泄漏 | 考前偷看了考卷 | 同一段信号切窗分到两侧是最隐蔽的一种 |
| 消融实验 | 拆零件看哪个真有用 | 证明创新模块不是凑数 |
| 边缘部署 | 把诊所开到村口 | 算力、时延、内存三重约束 |
| 复合故障诊断 | 同时感冒又胃疼，药还会互相作用 | 多标签 + 解耦，不能当独立事件 |
| 对比学习正样本 | 同一个人的两张不同照片 | 必须是"同一物理状态"，否则学偏 |

## 三、使用规则

1. 比喻只用来"建立直觉"，随后必须回到公式与数字，不许用比喻代替推导。
2. 每个比喻都要能回答"它对应公式里的哪一项"；答不上来就换一个。
3. 做简化演示时必须明说"此处为演示用简化，论文真实规模为…"。
4. 论文领域离故障诊断很远时，先用上表翻译，再决定是否做迁移讨论，不要硬扯电磁阀。
