# 术语分册：齿轮箱

> 齿轮箱是旋转机械里"特征频率最规整、也最容易被算错"的对象：所有故障特征都挂在**啮合频率**和**转频**这两根轴上。这册先把频率算对，再讲故障怎么改频谱形状。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 信号里怎么体现。

| 术语 | 一句话定义 | 生活化比喻 | 信号里怎么体现 |
|---|---|---|---|
| 齿轮箱（Gearbox） | 用齿啮合改变转速与转矩的传动装置 | 自行车的变速器 | 振动以啮合频率为主，故障改变边带与调制 |
| 齿数 z | 每个齿轮的轮齿数 | 齿轮的"牙"数 | 决定啮合频率与传动比，必须先从图纸或转速确认 |
| 转频 fr | 某根轴每秒转多少圈 | 心跳 | 输入/输出各有一个，是所有边带间距的来源 |
| 传动比 i | 输入转速与输出转速之比 `i = z2/z1 = fr1/fr2` | 变速档位 | 从转速差可以反推齿数比，验证齿数是否算错 |
| 啮合频率 GMF | 单位时间内有多少对齿啮合 `GMF = z·fr` | 每秒咬合多少次 | 频谱上最强的成分之一，故障在它两侧长边带 |
| 啮合谐波 | 2×GMF、3×GMF 等 | 主音的高八度 | 早期磨损使高次谐波抬升 |
| 调制（Modulation） | 一个频率的幅值/相位被另一个慢信号周期性改变 | 音量的周期性起伏 | 出现"载波 ± 调制频率"的边带 |
| 边带（Sideband） | 主峰两侧间隔等于调制频率的成分 | 主音旁的和声 | 边带间距 = 哪根轴的转频，就说明哪根轴上的齿轮有问题 |
| 边带族 | 多条等间距边带 | 一串和声 | 间距均匀 → 单齿缺陷；间距混杂 → 多齿或轴系问题 |
| 齿根裂纹 | 齿根部疲劳开裂 | 牙根裂了 | 早期几乎看不见，后期出现 1×转频调制与冲击 |
| 断齿（Broken Tooth） | 整齿或部分齿折断 | 掉了一颗牙 | 每转一次的强冲击，时域出现周期性脉冲，频谱边带密集 |
| 点蚀 / 剥落 | 齿面接触疲劳形成小坑 | 牙面蛀了个洞 | 啮合频率处能量上升并伴随宽带噪声 |
| 齿面磨损 | 齿厚减薄的均匀或非均匀损失 | 牙磨平了 | 啮合谐波整体抬升、齿隙变大、噪声上升 |
| 胶合（Scuffing） | 润滑失效导致齿面局部熔焊撕裂 | 干摩擦把牙蹭掉 | 突发性高频能量与温升，常无先兆 |
| 齿隙（Backlash） | 一对齿非工作面之间的间隙 | 两颗牙之间的空档 | 换向冲击、低速敲击声，频谱出现转频谐波 |
| 啮合刚度 | 啮合过程中齿对刚度随啮合位置变化 | 咬合时忽硬忽软 | 造成 GMF 及其谐波，是"齿轮箱天然有边带"的根源 |
| 传递误差（TE） | 实际输出转角与理想转角的偏差 | 说好转一圈实际差一点 | 与振动强相关，是齿轮动力学分析的核心量 |
| 时域同步平均（TSA） | 按转频对齐后逐周期平均，压掉随机噪声 | 把每圈的录像对齐叠加 | 突出与特定轴同步的成分，需先有转速信号 |
| 残余信号（Residual） | 从 TSA 结果中减去啮合成分后的剩余 | 把主旋律抽掉听伴奏 | 齿根裂纹、断齿在残余信号里最清楚 |
| 包络谱 | 对带通信号取包络再做 FFT | 只看"敲击的节奏" | 找轴承与齿轮的冲击间隔 |
| 倒谱（Cepstrum） | 对对数谱再做一次 FFT | 看"和声之间的间距" | 边带族在倒谱上表现为单根峰，便于识别调制 |
| 阶次分析 | 把频率除以转频，变成"每转多少次" | 用"每圈几步"数拍子 | 变转速下特征峰固定在阶次上不漂移 |
| 行星齿轮系 | 太阳轮、行星轮、齿圈围绕行星架转动 | 太阳系 | 频率关系复杂，行星轮经过频率是关键 |
| 太阳轮 / 行星轮 / 齿圈 | 行星系的三个基本构件 | 中心、绕行者、外圈跑道 | 各自的故障有不同的调制对象（行星架/齿圈频率） |
| 行星架转频 | 行星轮绕太阳轮公转的频率 | 行星绕太阳一圈 | 行星轮故障常以它为调制频率 |
| 行星轮通过频率 | 单位时间内有多少个行星轮经过某固定点 | 摩天轮上的座舱经过 | 齿圈局部故障会以该频率被调制 |
| 定轴轮系 | 所有齿轮轴位置固定的普通齿轮箱 | 普通自行车链盘 | 频率关系简单，按 `GMF = z·fr` 逐级算即可 |
| 输入轴 / 输出轴 / 中间轴 | 齿轮箱的三类轴 | 入口、出口、中转站 | 每根轴都有自己的转频，边带要分别验算 |
| 装配偏心 | 齿轮安装中心与旋转中心不重合 | 车轮回正没装好 | 出现 1×转频调制 + 啮合频率受调 |
| 齿形误差 | 齿廓偏离理论渐开线 | 牙长得不标准 | 高次啮合谐波抬升，噪声随负载变化 |
| 润滑与油温 | 油膜状态与工作温度 | 关节的润滑液 | 缺油使啮合能量与温升同时上升 |
| 冲击脉冲指标 | 时域冲击的强度度量（如 SPM/AI） | 敲一下有多响 | 轴承与齿轮早期缺陷的常用趋势量 |
| 循环计数（雨流） | 把随机载荷分解成等幅循环 | 把乱七八糟的弯折理成一圈圈 | 用于疲劳寿命估计，配 Miner 累积损伤 |
| 齿轮箱健康指标 | 把多测点特征压成一个退化分数 | 体检综合评分 | 常用边带能量比、啮合谐波比、残余信号 RMS |

## 数字例子：两级齿轮箱的频率账

一级：输入齿轮 $z_1 = 20$，输入转频 $f_{r1} = 25$ Hz（1500 rpm）；大齿轮 $z_2 = 40$。

- 一级啮合频率：$GMF_1 = z_1 f_{r1} = 20 \times 25 = 500$ Hz
- 中间轴转频：$f_{r2} = f_{r1} \times \frac{z_1}{z_2} = 25 \times 0.5 = 12.5$ Hz
- 若中间轴小齿轮 $z_3 = 18$，二级啮合频率：$GMF_2 = z_3 f_{r2} = 18 \times 12.5 = 225$ Hz

**读法**：如果频谱在 500 Hz 两侧出现间隔 12.5 Hz 的边带，说明调制来自**中间轴**——也就是"一级大齿轮或二级小齿轮"这一对；如果边带间隔是 25 Hz，才轮到输入轴。**边带间距是定位故障齿轮的唯一可靠线索，幅值大小不是。**

## 数字例子：倒谱为什么能看边带

设某段频谱在 500 Hz 附近有间隔 12.5 Hz 的一族边带（k = −3…+3）。对数谱上它们是等间距的"梳齿"，再做一次 FFT，会在倒谱时间 $1/12.5 = 0.08$ s 处出现一根孤立峰。

**读法**：倒谱把"一族边带"压成"一根峰"，人眼不用数边带就能读出调制周期 0.08 s。工程上常用它快速判断"调制到底来自哪根轴"。
