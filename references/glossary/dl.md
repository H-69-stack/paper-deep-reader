# 术语分册：深度学习

> 论文里的"创新模块"九成落在这册里：卷积、注意力、图网络、自监督、域适应。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 在故障诊断里的用法。

| 术语 | 一句话定义 | 生活化比喻 | 在故障诊断里的用法 |
|---|---|---|---|
| 神经网络（Neural Network） | 多层线性变换 + 非线性激活堆起来的函数拟合器 | 一层层筛选，每层只留自己关心的特征 | 诊断模型的主干，输入常是时频图或原始振动 |
| 前向传播（Forward） | 输入逐层算到输出 | 流水线从原料走到成品 | 推理阶段只做这一步 |
| 反向传播（Backprop） | 用链式法则从损失反推每个参数的梯度 | 成品不合格，逐道工序追责 | 训练的本质，显存主要花在存中间结果上 |
| 激活函数（ReLU / Sigmoid / Tanh / GELU） | 给网络加非线性，否则多层等价于一层 | 每道工序后加一道"合格/不合格"闸门 | ReLU 最常用，输出层用 Sigmoid/Softmax |
| Softmax | 把一组打分变成概率分布 | 把几个候选按支持度分蛋糕 | 多分类诊断的输出层 |
| 全连接层（FC） | 每个输入连到每个输出 | 开全体会议，人人发言 | 常在特征提取之后做分类头 |
| 卷积（Convolution） | 用一个小核在输入上滑动做加权求和 | 拿放大镜在图上逐格扫，看有没有某种花纹 | 一维卷积直接扫振动序列提取局部冲击模式 |
| 卷积核 / 滤波器（Kernel） | 一组待学习的权重，决定"找什么花纹" | 刻好图案的印章 | 第一层核学到的常是不同频段的冲击响应 |
| 步长与填充（Stride / Padding） | 滑多远、边上补不补零 | 走一步跨几格、边界要不要留白 | 决定输出长度，影响感受野覆盖范围 |
| 池化（Pooling） | 局部取最大或平均，降维并增强平移不变性 | 一段路只记最高点 | 减小计算量，但会丢掉冲击的精细时刻 |
| 感受野（Receptive Field） | 输出一个点能"看到"输入多宽的范围 | 一个人能同时看到多宽的画面 | 要覆盖 2–3 个故障周期，否则学不到周期性 |
| 二维卷积（2D CNN） | 在图像上滑动的卷积 | 在照片上找边缘、纹理 | 输入时频图（CWT/STFT/GADF）时的主力 |
| 残差连接（Residual） | 输出 = 变换(x) + x，给梯度开一条直通路 | 电梯直达，不用每层都爬楼梯 | 深网络不退化，几乎成了默认配置 |
| 批归一化（BatchNorm） | 按批统计量标准化每层输入 | 每道工序前把零件摆正 | 加速收敛；小 batch 时可换 GroupNorm |
| Dropout | 训练时随机丢一部分神经元 | 每次开会随机缺席几个人，逼大家都会 | 小样本诊断常用的正则手段 |
| 循环网络（RNN） | 按时间步递推，带"记忆" | 边听边记，前面的话影响后面的理解 | 处理长序列退化趋势，但长依赖会梯度消失 |
| LSTM / GRU | 带门控的 RNN，能选择性记住/忘记 | 有"存档"和"删除"按钮的记事本 | RUL 预测、退化趋势建模的经典选择 |
| 注意力（Attention） | 按相关性给不同位置分配权重再汇总 | 开会时重点听关键发言人的话 | 让模型自动聚焦故障冲击所在时段 |
| 自注意力（Self-Attention） | 序列内部自己和自己算相关性 | 团队内部互相评估谁的话重要 | Transformer 的核心，能建模任意两时刻的关系 |
| 多头注意力（Multi-Head） | 并行做多组注意力再拼接 | 多个角度同时评估同一件事 | 不同头常分别关注不同频段/不同传感器 |
| Transformer | 完全基于注意力的序列模型 | 不按顺序传话，而是所有人同时互相看 | 振动序列、多传感器融合里的新主流主干 |
| 位置编码（Positional Encoding） | 给注意力补上"第几个"的信息 | 给每句话贴序号，否则顺序全乱 | 振动序列的相位信息部分靠它保留 |
| 图神经网络（GNN） | 在图的节点和边上做消息传递 | 每个车间把消息发给相邻车间再汇总 | 多传感器/多部件之间的拓扑关系建模 |
| GCN / GAT | 图卷积 / 图注意力，区别在邻居权重怎么定 | 邻居投票：等权 vs 按重要性加权 | 传感器网络、部件耦合关系建模常用 GAT |
| 自编码器（Autoencoder） | 编码压缩再解码重建，学正常数据的流形 | 让人凭记忆把一幅画默画出来 | 只用正常数据训练，重建误差大即异常 |
| 变分自编码器（VAE） | 编码到概率分布再采样解码 | 不记死答案，记"这类答案大概长什么样" | 生成故障样本、做潜空间可视化 |
| 生成对抗网络（GAN） | 生成器造假、判别器鉴假，互相对抗提升 | 造假币的和验钞员互相较劲 | 故障样本扩充（如生成不同损伤程度的信号） |
| 对比学习（Contrastive） | 拉近同类样本、推远异类样本 | 把同款零件放一起，不同款分开放 | 无标签预训练，跨工况特征对齐效果好 |
| 自监督学习 | 用数据自身构造监督信号 | 把拼图打乱再让自己拼回去 | 少标签场景的预训练范式 |
| 迁移学习（Transfer Learning） | 把源域学到的知识用到目标域 | 会骑自行车的人学摩托车更快 | 实验室数据训练 → 现场数据微调 |
| 微调（Fine-tuning） | 在预训练模型上用少量新数据继续训练 | 换城市开车，只需熟悉新路况 | 冻结主干只调分类头是常用轻量方案 |
| 域适应（Domain Adaptation） | 显式对齐源域与目标域的特征分布 | 让两个方言区的人学会互相听懂 | 变工况诊断的核心方法（MMD、对抗对齐） |
| 域泛化（Domain Generalization） | 训练时看不到目标域，也要在它上面好用 | 没去过的地方也要能开 | 比域适应更难，也更贴近工程现实 |
| 知识蒸馏（Distillation） | 用大模型教小模型 | 老专家带徒弟，传的是"手感" | 把大模型压到边缘设备上部署 |
| 小样本 / 元学习（Meta-Learning） | 学会"怎么学"，几例即可适应新类 | 掌握学习方法，换科目也能快速上手 | 新故障类型几乎没有标注样本时的路子 |
| 类别中心 / 原型（Prototype） | 每个类在特征空间里的代表点 | 每个班的"标准照" | 原型网络做小样本诊断，可解释性较好 |
| 可解释性（Grad-CAM / SHAP） | 指出模型是靠哪些输入位置/特征做出的判断 | 让模型交代"我是看这里下的结论" | 诊断模型落地前的必备说服工具 |

## 数字例子模板（一维卷积）

输入 x = [1, 2, 3, −1]，核 k = [1, 0, −1]，步长 1、不填充。
第 1 个位置：1×1 + 2×0 + 3×(−1) = −2
第 2 个位置：2×1 + 3×0 + (−1)×(−1) = 3
输出 y = [−2, 3]。
**读法**：这个核在做"相邻差"，凡是"往上走"的地方输出为负、"往下走"的地方为正——它就是一个突变的探测器。

## 数字例子模板（二维卷积）

3×3 输入全 1，核为 2×2 全 1，步长 1、不填充 → 输出 2×2，每个位置都是 1+1+1+1 = 4。
若核为边缘检测核 [[1,0],[0,−1]]，则输出为 [[0, 0], [0, 0]]——因为输入是平的，没有边缘。

## 数字例子模板（MMD 域对齐）

两组一维特征：源域 A = [0, 1]，目标域 B = [3, 4]（各 2 个点）。
各求均值：μ_A = 0.5，μ_B = 3.5，均值差 = −3。
MMD 的简化（只保留均值项、多项式核展开后）：MMD² ≈ (μ_A − μ_B)² = 9，MMD ≈ 3。
若把目标域整体平移 −3 变成 [0, 1]，则 μ 相同、MMD → 0。
**读法**：MMD 就是"两组数据的分布差多远"的可计算版本；训练时把它加进损失，等于强迫模型把两域特征拉到一起。真实实现用核函数（如 RBF）算的是分布的高阶矩，但"拉近均值"这个直觉是对的。
