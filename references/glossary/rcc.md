# 术语分册：导电滚环（RCC）

> **RCC = 导电滚环（Conductive Rolling Ring），用户语境下就指它**：靠滚动接触而非滑动接触把电流从静止侧送到旋转侧的环形导电部件。它的特殊之处是"电"与"摩擦"在同一界面上耦合——磨损改变接触、电弧又反过来烧蚀金属。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 故障/退化时的表现。
> 注意：滚环与滑环（slip ring）不是同一种东西，前者靠滚动、后者靠滑动；很多文献混用，读到时要看原文的接触方式。

| 术语 | 一句话定义 | 生活化比喻 | 故障/退化时的表现 |
|---|---|---|---|
| 导电滚环（RCC） | 用滚子/滚珠在环面上滚动实现旋转侧导电的部件 | 给旋转的吊扇送电的"滚动的插头" | 接触电阻波动、滚道点蚀、磨屑桥接 |
| 滚动接触 vs 滑动接触 | 接触点相对速度为零 / 存在相对滑移 | 轮胎滚动 / 轮胎打滑 | 滚动磨损低但接触面积小、易间歇；滑动磨损大但接触稳定 |
| 滚环本体 | 与转动轴同轴、表面镀导电层的环件 | 电的"跑道" | 环面沟槽、镀层磨穿、椭圆度变大 |
| 滚子 / 滚珠 | 在环面与静止件之间滚动的导电体 | 跑在跑道上的跑者 | 点蚀、压痕（brinelling）、碎裂 |
| 电刷 / 触点（Brush / Contact） | 与环面保持压力接触的导电件（部分结构为弹片） | 压在跑道上的"手指" | 磨损变短、压力衰减、接触面烧蚀 |
| 刷握与弹簧 | 固定触点并提供接触压力的机构 | 手指按下去的力度 | 弹簧疲劳 → 压力不足 → 接触电阻升高、打火 |
| 接触压力 | 触点与环面之间的法向力 | 按多紧 | 过小打火，过大磨损加快，存在最佳区间 |
| 收缩电阻（Constriction Resistance） | 电流挤过微小真实接触点产生的电阻 | 多车道变单车道 | 表面越粗糙、压力越小，收缩电阻越大 |
| 膜电阻（Film Resistance） | 氧化膜/污染膜带来的附加电阻 | 接头上的一层锈 | 呈非线性、随电压变化，是"接触电阻为什么时大时小"的主因 |
| 接触电阻 `R_c` | 界面等效电阻，`R_c ≈ ρ/(2a) + R_film`（单点，a 为接触斑点半径） | 两个金属面只有几个点真的碰上 | 缓慢上升 = 退化；跳变 = 电弧或磨屑 |
| 动态接触电阻波动（DCR fluctuation） | 旋转一圈内接触电阻的周期性起伏 | 灯一闪一闪 | 随转角周期变化，频谱上出现转频及其倍频 |
| 接触压降 | 电流通过接触界面产生的电压降 `U = I·R_c` | 水管接头处的水压损失 | 压降缓慢抬升是早期征兆；突增说明接触失效 |
| 载流密度 | 单位接触面积通过的电流 | 每根车道上的车流 | 超限 → 局部过热与电蚀加速 |
| 温升 | 焦耳热与摩擦热共同引起的温度上升 | 一直摩擦的手心发烫 | 与 `I²R` 和摩擦功率相关，可作在线监测量 |
| 电弧 / 打火（Arcing） | 接触分离或弹跳瞬间的击穿放电 | 冬天脱毛衣的噼啪 | 宽带高频冲击，电压上出现尖峰、电流上出现缺口 |
| 电弧能量 | 单次放电的能量 `E = ∫u·i dt` | 每次打火"烧掉"多少金属 | 能量越大，电蚀坑越深，是寿命的关键累积量 |
| 电蚀（Electrical Erosion） | 电弧烧蚀接触面形成凹坑 | 被电火花点出小坑的金属面 | 凹坑 → 接触更不稳 → 更多打火，是正反馈 |
| 微动磨损（Fretting） | 微小往复滑移造成的磨损与氧化 | 鞋里进了沙子反复磨 | 产生红色氧化粉（fretting corrosion），接触电阻升高 |
| 磨屑 / 碳粉 | 磨损产生的金属或石墨颗粒 | 铅笔屑 | 堆积造成短路或桥接，也会加剧磨损 |
| 磨屑桥接 | 导电颗粒搭成临时通路 | 两电极之间落了根铁丝 | 接触电阻突然变低再突然恢复，产生随机尖峰 |
| 环面沟槽 | 长期运行在环面磨出的环形凹槽 | 跑道被压出车辙 | 滚子通过时产生周期性冲击，振动频谱出现转频整数倍 |
| 环面跳动（Runout） | 环面几何偏心导致的径向/轴向跳动 | 唱片不平 | 每转一次的振动与电阻波动，可伪装成故障 |
| 镀层（Ag / Ni / Au） | 环面与触点的导电减摩层 | 涂在跑道上的一层漆 | 磨穿后基体氧化，电阻阶跃上升 |
| 摩擦力矩 | 滚环转动时需克服的阻力矩 | 门轴越用越涩 | 上升 → 驱动电流增加、温升上升 |
| 四线法测电阻 | 用两对线分别通流与测压，消除引线电阻 | 用两个秤分别称"篮子"和"篮子加东西" | 在线监测接触电阻的标准方法 |
| 绝缘电阻 | 导电通路与外壳/其他通道之间的绝缘能力 | 电线皮破没破 | 下降 → 漏电、串扰，严重时短路 |
| 通道数与串扰 | 多路滚环之间的电气隔离程度 | 多根电话线捆在一起 | 通道间容性/感性耦合，噪声互相串入 |
| 转速上限（dn 值） | 接触面线速度允许的上限 | 跑道限速 | 超限后弹跳与打火剧增 |
| 接触弹跳（Bounce） | 滚动体在高速下与环面瞬间脱离 | 车轮过减速带会跳 | 每次脱离都是一次潜在打火，转得越快越频繁 |
| 电噪声 / EMI | 打火产生的宽带电磁干扰 | 收音机里的沙沙声 | 干扰同轴的传感器信号，诊断前要先做去噪 |
| 转速信号 | 由滚环或编码器给出的每转脉冲 | 秒表的"滴" | 既用于测转速，也常被本身的噪声污染 |
| 寿命与磨损率 | 触点磨损到极限所经历的时间/转数 | 铅笔能用多久 | 与电流、压力、湿度、粉尘强相关，厂家曲线只作参考 |
| 故障模式（FMEA） | 把"怎么坏、坏了的后果、怎么发现"列成表 | 体检项目的风险清单 | 常见：磨穿、打火电蚀、卡滞、绝缘失效、断线 |
| 与振动的耦合 | 电故障引起振动、振动又加剧电故障 | 两个病互相加重 | 只做振动诊断会漏电蚀，只做电诊断会漏机械磨损 |

## 数字例子一：接触电阻有多小、波动有多大

取银镀层有效电阻率 $\rho = 2\times10^{-8}\ \Omega\cdot m$，单个接触斑点半径 $a = 20\ \mu m$，并联斑点 $n = 10$ 个，膜电阻 $R_{film} = 0.5\ m\Omega$。

收缩电阻（多点近似）：$R_s \approx \frac{\rho}{2na} = \frac{2\times10^{-8}}{2 \times 10 \times 20\times10^{-6}} = 5\times10^{-5}\ \Omega = 50\ \mu\Omega$。

接触电阻：$R_c = R_s + R_{film} \approx 0.05 + 0.5 = 0.55\ m\Omega$。

**读法**：正常的接触电阻是**亚毫欧到毫欧**量级。如果论文里报的接触电阻是几欧姆，那测的多半是"整条回路"而不是接触点本身，两者不能混着比。

## 数字例子二：压降波动如何变成"假故障"

24 V 供电、负载电流 2 A。接触电阻从 5 mΩ 漂到 50 mΩ：

- 压降：$U = I R_c$，从 $2 \times 0.005 = 10$ mV 变到 $2 \times 0.05 = 100$ mV
- 接触点焦耳热：$P = I^2 R_c$，从 $4 \times 0.005 = 20$ mW 变到 $4 \times 0.05 = 200$ mW

**读法**：10 mV 的压降在 24 V 系统里只占 0.04%，传感器完全看不出来；但 200 mW 集中在几十微米的接触斑点上，足以让局部温度显著上升。所以**早期征兆是温升，不是电压**。

## 数字例子三：一次打火烧掉多少能量

24 V、2 A 的回路，触点弹跳持续 $200\ \mu s$：

$E = u\,i\,t = 24 \times 2 \times 200\times10^{-6} = 9.6\times10^{-3}\ J \approx 9.6$ mJ。

**读法**：9.6 mJ 听起来很小，但假设一次弹跳烧蚀掉约 $10^{-12}$ m³ 量级的金属、并且每秒弹跳几十次，转一小时的累积损伤就足以在环面上留下可见凹坑。这就是"电蚀是累积量、不是单次事件"的物理含义。
