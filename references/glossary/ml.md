# 术语分册：机器学习基础

> 故障诊断里 80% 的"创新"其实是在这套老概念上做排列组合。先读索引选册，这一册讲样本、划分、损失、优化、传统模型与评估逻辑。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 在故障诊断里的用法。

| 术语 | 一句话定义 | 生活化比喻 | 在故障诊断里的用法 |
|---|---|---|---|
| 样本（Sample） | 一条完整记录，如"一段 1024 点振动 + 它的标签" | 一张带名字的照片 | 一个样本通常是一段 1 秒的振动窗 |
| 特征（Feature） | 从原始数据里算出的、更紧凑的数值 | 从一张全身照里量出身高体重肩宽 | RMS、峭度、包络谱峰值就是经典特征 |
| 标签（Label） | 样本对应的答案，如"内圈故障" | 照片背后写的名字 | 实验室台架能按故障件打标，现场往往没有 |
| 训练集 / 验证集 / 测试集 | 学、调、考三份互不重叠的数据 | 课本、模拟考、高考 | 测试集泄漏是最常见的"虚高准确率"来源 |
| 交叉验证（Cross-Validation） | 轮换当验证集，多次取平均 | 换几个人轮流当考官 | 样本少时比单次划分更可靠，k 常取 5 或 10 |
| 过拟合（Overfitting） | 训练集表现好、新数据表现差 | 把练习册答案背下来，遇到新题就傻 | 深度学习诊断模型在单一工况上极易过拟合 |
| 欠拟合（Underfitting） | 训练集都学不好，模型太简单 | 用直线去拟合一条弯路 | 只堆一层网络或特征太少时出现 |
| 正则化（L1 / L2） | 给参数大小加惩罚，抑制过拟合 | 规定"不许写太复杂的解题步骤" | 小样本诊断任务里 L2 权重衰减几乎是必加项 |
| 偏差-方差权衡 | 模型太简单偏差大，太复杂方差大 | 秤不准（偏差）vs 每次称都不一样（方差） | 解释"为什么加深网络反而变差"的标准语言 |
| 损失函数（Loss） | 衡量预测与真值差多少的标量函数 | 考试扣分规则 | 分类用交叉熵，回归用 MSE，RUL 常用自定义评分 |
| 交叉熵（Cross-Entropy） | 分类损失，正确类概率越低罚得越狠 | 押错宝的代价 | 诊断分类的主力损失；类别不平衡时要加权 |
| 均方误差（MSE） | 回归损失，误差平方的平均 | 打靶偏离靶心的平方距离 | RUL、退化指标预测的标准损失 |
| 梯度下降（Gradient Descent） | 沿损失下降最快的方向挪一小步 | 蒙眼下山，每一步朝最陡的方向走 | 一切深度模型训练的底层机制 |
| 学习率（Learning Rate） | 每次挪多大一步 | 下山时步长 | 太大震荡不收敛，太小训练到天亮 |
| 批大小（Batch Size） | 一次用多少样本算一次梯度 | 一次看几道题再总结规律 | 小 batch 噪声大但泛化常更好，显存是硬约束 |
| 轮次（Epoch） | 把训练集完整过一遍 | 课本从头翻一遍 | 报"训练 100 epoch"要说清是早停前还是满跑 |
| 早停（Early Stopping） | 验证集不再变好就停 | 模拟考连续退步就停止加练 | 小样本诊断的标准防过拟合手段 |
| 优化器（Adam / SGD） | 决定怎么用梯度更新参数的算法 | 下山的策略：匀速走还是带惯性冲 | Adam 省心，SGD+动量在文献里常能刷更高精度 |
| 批量归一化（BatchNorm） | 每层输入按批统计量标准化 | 每道题先换算成同一难度再算 | 加速收敛、对学习率不敏感，但小 batch 时统计量不稳 |
| 数据泄漏（Data Leakage） | 测试集信息混进了训练过程 | 考前偷看了考卷 | 同一段振动切窗后分到训练/测试两侧，是最隐蔽的泄漏 |
| 类别不平衡（Imbalance） | 正常样本远多于故障样本 | 一千个健康人里找一个病人 | 现场数据常态，需要重采样或代价敏感 |
| 重采样（过采样 / 欠采样） | 复制少数类或丢弃多数类来配平 | 给稀有的菜多上几盘 | SMOTE 在振动信号上要先想清物理意义 |
| 代价敏感（Cost-Sensitive） | 不同错分的代价不同，写进损失 | 漏诊比误诊罚得重 | 漏报故障的代价远高于误报，要显式加权 |
| K 近邻（KNN） | 看最近的 k 个邻居是谁就跟着投谁 | 买房看同小区成交价 | 小样本基线的默认选择，对特征尺度极敏感 |
| 支持向量机（SVM） | 找一条间隔最大的分界面 | 在两堆点之间划一条最"宽敞"的线 | 小样本、高维特征下的经典强基线 |
| 核函数（Kernel） | 把低维分不开的数据映射到高维再分 | 把平面上的两团点抬到空中再切一刀 | RBF 核在振动特征上常用，γ 要调 |
| 决策树（Decision Tree） | 一串 if-else 规则把样本分到叶子 | 医院分诊流程图 | 可解释性好，常用来做特征重要性分析 |
| 随机森林（Random Forest） | 很多棵树投票，每棵只看部分特征/样本 | 一群医生会诊 | 诊断基线里最稳的一档，几乎不用调参 |
| 梯度提升树（GBDT / XGBoost） | 一棵棵树去拟合前面的残差 | 每次补上"上次没答对的部分" | 表格型特征上的最强传统模型 |
| 主成分分析（PCA） | 找方差最大的几个方向做降维 | 给一屋子人拍集体照，找最能看清差别的角度 | 高维特征可视化与去冗余，但会打散物理解释 |
| 聚类（K-Means 等） | 无标签时按相似度分组 | 把一筐零件按大小自动分堆 | 未知故障模式的发现，聚出的簇要人工解释 |
| 异常检测（Anomaly Detection） | 只学正常样本，偏离就报警 | 门卫只认熟脸，生人即拦 | 现场只有正常数据时的主力范式（OCSVM、自编码器） |
| 特征选择（Feature Selection） | 从一堆特征里挑出有用的 | 体检只查关键几项 | 去掉冗余特征能显著降低小样本过拟合 |
| 标准化（Standardization） | 减均值除标准差，让各特征同尺度 | 把不同科目分数换算成标准分 | SVM/KNN/神经网络前必做 |
| 滑窗（Sliding Window） | 用固定长度窗口在长信号上滑动切样本 | 用相框在长卷照片上逐段取景 | 窗口长度要覆盖至少 2–3 个故障冲击周期 |
| 集成学习（Ensemble） | 多个模型合起来决策 | 多个专家投票定方案 | 多传感器多模型融合的常用手法 |
| 半监督学习 | 少量标签 + 大量无标签一起训练 | 老师只批几本作业，其余靠自批互批 | 现场标注贵，伪标签是常见套路 |
| 小样本学习（Few-Shot） | 每类只有几个样本也要学会分 | 只见过三张猫的照片就要认出猫 | 新故障类型几乎没有样本时的核心痛点 |

## 数字例子模板（Softmax + 交叉熵）

三个类别打分 z = [1, 2, 3]。
e^1 = 2.72，e^2 = 7.39，e^3 = 20.09，和 = 30.20。
概率 p = [0.09, 0.24, 0.67]——三个数加起来等于 1。
真实类别是第 3 类时，损失 = −ln(0.67) ≈ 0.40；
若模型很自信地给对了（p = 0.95），损失 = −ln(0.95) ≈ 0.05；
若给了错类 0.09，损失 = −ln(0.09) ≈ 2.41。
**读法**：交叉熵就是"正确类概率的对数取负"，越自信地错，罚得越狠。
