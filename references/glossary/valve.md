# 术语分册：液压电磁阀

> 液压电磁阀是"电 → 磁 → 力 → 位移 → 流量/压力"的多级转换件，故障往往先出现在中间某一级。这册按这条链组织：线圈、磁路、阀芯、阀口、油液。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 故障时的典型表现。

| 术语 | 一句话定义 | 生活化比喻 | 故障时的典型表现 |
|---|---|---|---|
| 电磁阀 | 用电信号控制液压油路通断/方向/压力的元件 | 油路的红绿灯加闸门 | 不动作、动作慢、抖动、内泄 |
| 阀芯 / 阀套 | 阀内相对滑动的柱塞与套筒，二者间隙决定泄漏 | 注射器活塞与筒壁 | 间隙磨大 → 内泄漏；污染 → 卡滞 |
| 配合间隙（Clearance） | 阀芯与阀套之间的径向间隙，通常几微米 | 活塞与筒壁那一丝缝 | 泄漏与间隙是**三次方**关系，间隙翻倍泄漏约 8 倍 |
| 内泄漏 | 高压腔向低压腔的泄漏流量 | 水龙头关不严还滴水 | 保压能力下降，压力曲线缓慢下滑，油温升高 |
| 卡滞（Stiction） | 阀芯因污染/磨损/油膜吸附卡住不动 | 抽屉滑轨卡住 | 指令与响应不同步，出现滞环、台阶、死区变大 |
| 滞环（Hysteresis） | 同一控制量在上升与下降行程中对应不同输出 | 老式收音机旋钮的回差 | 闭环控制振荡，压力/流量曲线出现回环 |
| 死区（Deadband） | 输入变化但输出不变化的区间 | 方向盘的空行程 | 小信号控制迟钝，低频跟踪误差大 |
| 线圈（Solenoid Coil） | 通电产生磁力驱动阀芯的绕组 | 电磁铁 | 匝间短路、老化 → 电流曲线畸变、吸合力下降 |
| 匝间短路 | 线圈内部相邻匝绝缘破坏而短接 | 弹簧有几圈粘在一起 | 等效电阻下降、电感下降、温升异常 |
| 线圈电阻 | 绕组的直流电阻，随温度上升 | 导线的"粗细" | 冷态/热态差异大，可用作温度估计 |
| 电感与时间常数 | `τ = L/R`，决定电流上升快慢 | 水管灌满需要的时间 | 阀芯吸合瞬间电感突变，电流曲线出现拐点 |
| 吸合电流 / 保持电流 | 克服弹簧与液压力所需 / 维持吸合所需电流 | 推开门要用力，扶着不用 | 吸合电流上升说明摩擦或液压力变大 |
| 电磁力 | `F = B²A/(2μ0)`，与气隙磁密平方成正比 | 磁铁的吸力 | 气隙增大（磨损）→ 力迅速下降 |
| 气隙（Air Gap） | 磁路中的非磁性间隙 | 磁铁与被吸物之间的空隙 | 磨损或装配误差使气隙变大，响应变慢 |
| 剩磁 | 断电后铁芯残留的磁感应 | 关掉电磁铁还粘着 | 断电释放延迟，回位不到位 |
| 弹簧复位 | 断电后靠弹簧把阀芯推回原位 | 松手自动回弹的门 | 弹簧疲劳 → 复位慢或不到位 |
| 响应时间 | 从给电到阀芯到位的时间 | 指令到执行的反应速度 | 上升 → 系统动态变差，严重时动作失败 |
| 开启压力 / 关闭压力 | 阀开始/停止导通对应的压力 | 水龙头的开启水压 | 与设计值偏离说明弹簧或摩擦变化 |
| 压力-流量特性 | 阀口开度与通过流量的关系 | 水龙头拧多少出多少水 | 斜率变化说明阀口磨损或污染 |
| 阀口流量公式 | `Q = Cd·A(x)·√(2Δp/ρ)`，与压差开方成正比 | 水管越粗、压差越大，出水越多 | 同样开度下流量偏小 → 阀口堵塞或磨损改变型线 |
| 流量系数 Cd | 实际流量与理论流量的比值，典型 0.6–0.8 | 水管的"通畅程度" | 下降说明阀口毛刺、结垢 |
| 空化 / 气蚀 | 局部压力低于饱和蒸气压时油液汽化再溃灭 | 开水壶里的气泡炸裂 | 高频宽带噪声、阀口麻点、流量不稳 |
| 液动力（Flow Force） | 油流改变方向时对阀芯的反作用力 | 消防水枪的后坐力 | 大流量时把阀芯往关的方向推，需要更大电磁力 |
| 摩擦力 | 阀芯与阀套间的机械阻力 | 抽屉的涩感 | 使最小动作电流上升、滞环变宽 |
| PWM 驱动 | 用脉宽调制控制线圈平均电流 | 快速开关水龙头来调水量 | 占空比与平均电流的关系受电感影响，低频 PWM 会抖动 |
| 颤振（Dither） | 在控制信号上叠加小幅高频振荡以减小滞环 | 轻轻抖动门把手防止卡住 | 频率/幅值不当反而加剧磨损 |
| 油液污染度 | 单位体积内颗粒的数量分级（ISO 4406 / NAS 1638） | 油里有多少沙子 | 超过阀的允许等级 → 卡滞、磨损加速 |
| 油液粘度 | 油的内摩擦，随温度显著变化 | 蜂蜜冷天更稠 | 粘度变化改变泄漏与响应时间，必须与温度一起看 |
| 油温 | 液压系统工作温度 | 体温 | 影响粘度、间隙配合、密封寿命 |
| 比例阀 / 伺服阀 | 按输入比例 / 按闭环反馈精确控制 | 旋钮 / 精密调节器 | 对零漂、滞环、分辨率要求高，诊断更难 |
| 换向阀 | 改变油流方向的开关阀（二位/三位） | 十字路口的信号灯 | 换向不到位 → 执行器不动作或爬行 |
| 先导式 vs 直动式 | 用小流量先导压力驱动主阀 / 电磁力直接驱动 | 用小手开大门 / 直接推门 | 先导孔堵塞是先导阀的典型故障 |
| 阀芯位移传感 | 直接测阀芯位置，用于闭环与诊断 | 给门装个开度计 | 多数工业阀没有，只能从电流/压力反推 |
| 电磁阀故障诊断的"三路信号" | 电流（电）、压力（液）、振动/位移（机） | 三张化验单一起看 | 单看一路难以区分电故障与机械故障 |

## 数字例子一：阀口流量

设阀口开度对应面积 $A = 4\ mm^2 = 4\times10^{-6}\ m^2$，压差 $\Delta p = 7$ MPa，油密度 $\rho = 870\ kg/m^3$，流量系数 $C_d = 0.6$。

流速：$v = \sqrt{2\Delta p/\rho} = \sqrt{2 \times 7\times10^{6} / 870} = \sqrt{16092} \approx 126.9\ m/s$

流量：$Q = C_d A v = 0.6 \times 4\times10^{-6} \times 126.9 \approx 3.05\times10^{-4}\ m^3/s$

换算：$3.05\times10^{-4} \times 1000 \times 60 \approx 18.3\ L/min$。

**读法**：流量与压差的**开方**成正比——压差翻四倍，流量才翻一倍。很多论文把"压差变化导致的流量变化"误归因为"阀口故障"，这是常见混淆。

## 数字例子二：间隙翻倍，泄漏涨多少

环形缝隙泄漏近似：$Q = \dfrac{\pi d h^3 \Delta p}{12 \mu L}$。

取 $d = 20$ mm、$L = 10$ mm、$\Delta p = 10$ MPa、$\mu = 0.04\ Pa\cdot s$：

- 间隙 $h = 5\ \mu m$：$Q = \dfrac{\pi \times 0.02 \times (5\times10^{-6})^3 \times 10^{7}}{12 \times 0.04 \times 0.01} \approx 1.6\times10^{-8}\ m^3/s \approx 0.001\ L/min$（约 1 mL/min）
- 间隙 $h = 10\ \mu m$：$h^3$ 变 8 倍 → $Q \approx 0.008\ L/min$（约 8 mL/min）

**读法**：间隙只翻一倍，泄漏涨 **8 倍**。这就是为什么"内泄漏"是阀磨损最灵敏的指标，也是为什么阀的配合间隙常被控制在微米级。
