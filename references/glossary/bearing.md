# 术语分册：滚动轴承振动诊断

> 轴承是旋转机械里最常坏的零件，也是 PHM 论文出现频率最高的对象。这册只讲"怎么从一个振动信号里判断是不是轴承、是哪个零件、坏到什么程度"。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 信号里怎么体现。

| 术语 | 一句话定义 | 生活化比喻 | 信号里怎么体现 |
|---|---|---|---|
| 转频 fr（Shaft Frequency） | 轴每秒转多少圈，单位 Hz | 心跳 | 频谱 1× 位置的峰，是所有特征频率的基准 |
| 内圈故障频率 BPFI | 滚道内圈上一点被滚动体反复碾过的频率 | 跑道内侧被踩的节拍 | 包络谱上 1×BPFI 及其谐波，常被转频调制出边带 |
| 外圈故障频率 BPFO | 外圈局部缺陷被滚动体碾过的频率 | 跑道外侧被踩的节拍 | 包络谱上 1×BPFO 及谐波，通常最干净（外圈不随轴转） |
| 滚动体故障频率 BSF | 单个滚动体上的缺陷与内外圈交替撞击的频率 | 跑者自己脚上有伤 | 冲击较弱、常被保持架频率调制，最难识别 |
| 保持架故障频率 FTF | 保持架旋转对应频率 | 维持队形的栏杆转一圈的节奏 | 低频调制，常表现为其他特征频率的边带 |
| 接触角 α | 滚动体与滚道的受力方向与径向的夹角 | 推车时斜着推 | 进入特征频率公式，角接触轴承不可忽略 |
| 节径 D / 滚动体直径 d | 滚动体中心的圆周直径 / 滚动体自身直径 | 跑道圆周长 / 轴承球大小 | 比值 d/D 是特征频率公式的关键参数 |
| 滚动体数 Z | 一圈里有几个滚动体 | 跑道上有几个跑者 | 进入 BPFO/BPFI 公式（除以 2 再乘 Z） |
| 故障四个阶段 | 早期高频共振 → 特征频率出现 → 谐波与边带 → 噪声抬升 | 生病：先不舒服 → 有症状 → 并发症 → 全身衰竭 | 阶段 1 只有高频能量上升（RMS 变化小），阶段 4 频谱糊成一片 |
| 早期故障点 FPT | 退化开始的时刻估计 | 感冒的第一天 | 由健康指标拐点或统计检验确定，RUL 预测的起点 |
| 共振解调 / 包络分析 | 先带通到结构共振带，再取包络做低频 FFT | 用听诊器只听"咚咚"不听杂音 | 步骤：带通（如 2–10 kHz）→ 希尔伯特包络 → FFT → 找 BPFO/BPFI |
| 希尔伯特变换 | 把实信号变成解析信号以取瞬时幅值/相位 | 给波形画一条"外套" | 包络谱的数学基础；也可求瞬时频率 |
| 带通频带选择 | 选哪一段频率做解调 | 收音机调台 | 选轴承座结构共振带（可用谱峭度自动选），选错等于白做 |
| 谱峭度（Spectral Kurtosis） | 各频带上峭度的大小，用来找"最像冲击"的频带 | 逐层试音找最清楚的那层 | 快速谱峭度图（FK）可自动定带通区间 |
| 峭度（Kurtosis） | 四阶矩，衡量冲击性 | 波形"尖不尖" | 早期敏感，但阶段 4 会回落，不能只看它 |
| 峰值因子（Crest Factor） | 峰值 / 有效值 | 最高音与平均音量之比 | 冲击型故障早期升高 |
| RMS（有效值） | 振动总能量 | 音量大小 | 晚期才明显上升，适合做趋势 |
| 包络谱峰值比 | 特征频率处峰值 / 该频带背景 | 在嘈杂里听清一句话的信噪比 | 用比值而不是绝对幅值，便于跨设备比较 |
| 特征频率谐波 | BPFO 的 2×、3× 等 | 主音的高八度 | 谐波越丰富通常说明冲击越尖锐 |
| 边带（Sideband） | 主峰两侧间隔等于调制频率的成分 | 主音旁的和声 | 内圈故障常见 fr 间隔边带；间距帮助确认调制源 |
| 转频调制 | 故障特征被 1× 转频调制 | 走路时一瘸一拐的节律 | 内圈故障随载荷区进出，幅值周期性起伏 |
| 打滑（Slip） | 滚动体并非纯滚动，实际频率略低于理论值 | 轮子打滑 | 实测特征频率常比计算值低 1%–2%，找峰要留容差 |
| 变转速影响 | 特征频率随转速线性缩放 | 心跳随运动强度变化 | 变工况必须先做阶次跟踪或角度域重采样 |
| 阶次分析（Order Analysis） | 把频率除以转频变成"每转几次" | 按"每圈几步"数拍子 | 变速下用阶次谱，特征峰固定在 BPFO/fr 这个比值上 |
| 角度域重采样 | 按转角等间隔重采样，消除转速波动 | 把录像按每圈一帧重排 | 计算阶次跟踪（COT）的常用实现 |
| 轴承寿命 L10 | 90% 可靠度下的额定寿命 | 保质期 | `L10 = (C/P)^p × 10^6` 转，球轴承 p=3、滚子 p=10/3 |
| 基本额定动载荷 C / 当量动载荷 P | 轴承能承受的载荷能力 / 实际等效载荷 | 承重上限 / 实际挑的担子 | 载荷越大寿命越短（三次方关系） |
| 游隙（Clearance） | 滚动体与滚道之间的间隙 | 门轴松了 | 游隙过大 → 冲击增强、特征频率谐波丰富 |
| 预紧（Preload） | 装配时施加的轴向压紧力 | 把螺丝拧紧一点 | 预紧不当 → 早期疲劳、温升异常 |
| 润滑状态 | 油膜厚度与粗糙度的比值（λ 值） | 地面有没有润滑 | 贫油 → 高频噪声与温升先升；过量 → 搅拌发热 |
| 保持架碰磨 | 保持架与滚动体/套圈的异常接触 | 栏杆挤到跑者 | 出现 FTF 及其谐波、宽带噪声 |
| 轴承电流（电蚀） | 轴电流经轴承放电造成滚道凹坑 | 轴承里打微型闪电 | 变频驱动常见；包络谱出现"平顶"宽峰而非尖锐谐波 |
| 健康指标 HI | 把多维特征压成一个 0–1 的退化分数 | 体检总评分 | 常用 RMS、峭度、包络能量加权或 PCA 第一主成分 |
| 剩余寿命 RUL | 从当前时刻到失效还剩多少时间 | 油表还能跑多少公里 | 在 FPT 之后用指数/线性/随机过程模型外推 |

## 数字例子：一台轴承的四个特征频率

设轴转频 $f_r = 25$ Hz（1500 rpm），滚动体数 $Z = 9$，节径比 $d/D = 0.2$，接触角 $\alpha \approx 0^\circ$（$\cos\alpha = 1$）。

- 外圈：$BPFO = \frac{Z}{2} f_r (1 - \frac{d}{D}) = 4.5 \times 25 \times 0.8 = 90$ Hz
- 内圈：$BPFI = \frac{Z}{2} f_r (1 + \frac{d}{D}) = 4.5 \times 25 \times 1.2 = 135$ Hz
- 滚动体：$BSF = \frac{D}{2d} f_r \left[1 - (\frac{d}{D})^2\right] = 2.5 \times 25 \times 0.96 = 60$ Hz
- 保持架：$FTF = \frac{f_r}{2} (1 - \frac{d}{D}) = 12.5 \times 0.8 = 10$ Hz

**读法**：如果包络谱在 90 Hz、180 Hz、270 Hz 上排成一串，就是外圈；在 135 Hz 附近且两侧各隔 25 Hz（转频）有边带，就是内圈。**先算这几个数，再去谱里找**——直接盯着谱找"最大的峰"是最常见的错误，因为最大的峰往往是转频或共振，不是故障频率。
