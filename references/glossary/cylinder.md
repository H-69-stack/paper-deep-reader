# 术语分册：液压缸

> 液压缸是"最容易从外部看着诊断"的执行元件：位移、压力、速度都能直接测。难点在于**内泄漏看不见**，只能从速度-负载关系、沉降量、压降曲线上反推。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 故障时的典型表现。

| 术语 | 一句话定义 | 生活化比喻 | 故障时的典型表现 |
|---|---|---|---|
| 液压缸（Cylinder） | 把液压能转成直线往复运动的执行元件 | 打针的针筒 | 动作慢、爬行、沉降、无力 |
| 缸筒 / 活塞 / 活塞杆 | 缸的三个基本零件 | 筒、塞、杆 | 划伤、拉毛、圆度超差 |
| 无杆腔 / 有杆腔 | 活塞两侧的容腔，面积不同 | 针筒两端 | 面积比决定伸出/缩回的速度与推力不同 |
| 有效面积 A | 压力作用的有效面积（无杆腔 `A = πD²/4`，有杆腔 `A = π(D²−d²)/4`） | 受力面的大小 | 推力/速度都从这个数出发 |
| 推力 F | 液压缸能输出的力 `F = p·A` | 力气大小 | 同一压力下推力变小 → 内泄漏或面积变化 |
| 速度 v | 活塞杆伸出/缩回速度 `v = Q/A` | 出手快不快 | 速度随负载明显变慢 → 内泄漏 |
| 内泄漏 | 活塞两侧之间的窜油 | 针筒活塞密封不严，推时往回漏 | 速度变慢、保压掉压，但外部看不见泄漏 |
| 外泄漏 | 油漏到缸外 | 针筒漏在手上 | 活塞杆处渗油、地面油迹 |
| 保压试验 | 关死进出口，测压力随时间下降 | 扎紧气球看漏多快 | 压降速率是内泄漏最直接的量化指标 |
| 沉降 | 负载作用下活塞杆缓慢回缩 | 举着重物手慢慢垂下 | 保压压降 + 位移缓慢变化 |
| 爬行（Stick-Slip） | 低速时走走停停的抖动 | 门轴干涩时一卡一滑 | 速度曲线呈锯齿，伴随"咯噔"振动与噪声 |
| 爬行三要素 | 摩擦非线性、润滑不足、系统刚度低 | 涩、干、软 | 三者任一恶化都会诱发低速爬行 |
| 静摩擦与动摩擦差 | 起动摩擦大于滑动摩擦的程度 | 推箱子的第一下最费劲 | 差值越大越容易爬行 |
| 密封件（活塞密封/杆密封） | 阻止油液窜漏的橡胶/聚氨酯件 | 针筒的黑胶塞 | 老化、唇口翻转、划伤 → 内/外泄漏 |
| 支承环 / 导向套 | 承受侧向力并导向活塞杆的元件 | 门的合页 | 磨损后活塞杆偏磨、杆密封加速失效 |
| 活塞杆镀层 | 杆表面的硬铬层，防腐耐磨 | 镀铬层掉了就生锈 | 划伤后先漏后锈，锈蚀又磨密封 |
| 缓冲装置 | 行程末端的节流缓冲 | 关门前的减速器 | 失效 → 端部冲击、结构松动 |
| 行程与两端限位 | 可运动的长度与机械止点 | 电梯的楼层 | 行程误差说明传感器或机械限位问题 |
| 位移传感器 | 测活塞杆位置的传感器（磁致伸缩/拉线/激光） | 给门装开度计 | 漂移或跳变会造成"假位置"，必须先排除 |
| 力/压力传感器 | 测推力的压力表或压力变送器 | 体重秤 | 两腔压力差 × 面积 = 实际出力 |
| 背压 | 回油侧的阻力压力 | 排队出站的人流 | 背压过高 → 有效推力下降、发热 |
| 负载敏感 | 按负载自动调整压力的控制方式 | 按重量给力度 | 故障时压力不跟随负载，系统发热 |
| 双缸同步 | 两个缸同时动作保持行程一致 | 两个人抬担架要齐步 | 同步误差 = 两缸泄漏量差异的直接反映 |
| 空气混入 | 油中混有气泡导致动作发软 | 针筒里有气泡 | 动作迟滞、抖动、压力表指针摆动 |
| 油液污染 | 颗粒物加速密封与缸壁磨损 | 沙粒进了轴承 | 拉缸、划伤、密封早期失效 |
| 油温 | 影响黏度与泄漏量的温度 | 体温 | 温度升高使内泄漏增大、速度变慢 |
| 划伤 / 拉缸 | 缸筒内壁被硬颗粒划出沟槽 | 镜面被钥匙划了 | 内泄漏突增，磨损进入恶性循环 |
| 圆度 / 圆柱度误差 | 缸筒截面与轴线的几何偏差 | 管子不圆 | 局部间隙变大 → 偏磨与泄漏 |
| 端部冲击 | 行程到端部时的机械撞击 | 撞门 | 高频振动与噪声，长期损伤焊缝与紧固 |
| 液压缸诊断的四路信号 | 压力（两腔）、位移、流量、振动 | 四张化验单 | 单看压力分不清内泄漏与负载变化 |
| 负载估计 | 由两腔压差乘面积反推外力 | 从用力大小猜重量 | 与位移一起可做"负载-速度"诊断图 |
| 效率与损耗 | 输出机械功与输入液压功之比 | 干活的性价比 | 内泄漏与摩擦是两大损耗源，均随温度上升 |

## 数字例子：推力与速度

设缸径 $D = 50$ mm，杆径 $d = 28$ mm，供油压力 $p = 10$ MPa，流量 $Q = 20$ L/min。

无杆腔面积：$A_1 = \pi D^2/4 = 3.1416 \times 0.05^2/4 = 1.963\times10^{-3}\ m^2$

- 伸出推力：$F_1 = pA_1 = 10\times10^{6} \times 1.963\times10^{-3} \approx 19.6$ kN
- 有杆腔面积：$A_2 = \pi(0.05^2 - 0.028^2)/4 = 3.1416 \times (0.0025-0.000784)/4 \approx 1.348\times10^{-3}\ m^2$
- 缩回推力（同压力）：$F_2 \approx 13.5$ kN
- 伸出速度：$v_1 = Q/A_1 = \frac{20/1000/60}{1.963\times10^{-3}} \approx 0.17\ m/s = 170$ mm/s

**读法**：伸出与缩回的力差约 31%，速度差约 46%，都是面积差造成的，**不是故障**。判断故障要看"同一负载下速度是否明显低于设计值"。

## 数字例子：保压压降估内泄漏

缸在 10 MPa 下保压，测得 1 分钟后压力降到 9.2 MPa。缸与管路总容积 $V = 2$ L，油液体积弹性模量取 $K = 1.4$ GPa。

压力降：$\Delta p = 0.8$ MPa。由 $\Delta V = V \cdot \Delta p/K = 2\times10^{-3} \times 0.8\times10^{6}/1.4\times10^{9} \approx 1.14\ mL$。

**读法**：1 分钟漏掉约 1.1 mL，等效泄漏率约 **1 mL/min**。这与 `valve.md` 里 5 µm 间隙的泄漏量同量级，说明"密封良好时本来就漏得很少"——一旦测到几十 mL/min 的压降速率，基本可以判定内泄漏。

> 注意：实测压降还包含油液压缩、管路膨胀与温度下降的影响，上面的算式是**量级估计**，精确定量需要做温度补偿与容积标定。
