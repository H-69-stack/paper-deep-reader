# 术语分册：数学符号速查

> 精讲里凡是出现公式，符号第一次出现就要在这里能查到"它叫什么、通常表示什么、量纲是什么"。
> 用法：写公式时先查这张表，不要把 \alpha 当成"某个神秘系数"糊过去。

## 一、常用符号

| 符号 | 读法 | 通常含义 | 注意 |
|---|---|---|---|
| $x_t$ | x 下标 t | 第 t 个时刻的采样值 | 时间索引，单位常为采样点 |
| $N$ | 大写 N | 样本数 / 采样点数 / 批大小 | 三种含义都在用，看上下文 |
| $T$ | 大写 T | 序列长度 / 周期 / 转置 | 周期 $T=1/f$；矩阵转置 $A^{\mathsf T}$ |
| $f$ / $f_s$ | 小写 f | 频率 / 采样频率（Hz） | $f_s$ 一定要与 Nyquist 一起讲 |
| $\omega$ | omega | 角频率（rad/s），$\omega = 2\pi f$ | 工程里 2π 常被漏掉，是经典错误点 |
| $\lambda$ | lambda | 正则化系数 / 特征值 / 波长 | 不同章节含义不同，要逐处交代 |
| $\eta$ | eta | 学习率（也常写作 $\alpha$ 或 $lr$） | 与 $\alpha$ 容易冲突，全文统一 |
| $\theta$ | theta | 模型参数集合 / 角度 | 参数向量常写 $\boldsymbol{\theta}$ |
| $\mu$ / $\sigma$ | mu / sigma | 均值 / 标准差 | 标准化公式 $z=(x-\mu)/\sigma$ |
| $\sigma(\cdot)$ | sigma of | 也常指 Sigmoid 函数 | 与标准差撞车，看有没有括号 |
| $\Sigma$ | 大写 Sigma | 协方差矩阵 / 求和号 | 大写希腊字母常表示矩阵 |
| $\sum$ | 求和 | 对指标从 1 到 N 累加 | 手算例子就把它展开成几项加 |
| $\prod$ | 连乘 | 乘积 | 似然函数里常见 |
| $\int$ | 积分 | 连续求和 | 手算时用离散求和近似并注明 |
| $\partial$ | partial | 偏导 | 反向传播公式的核心符号 |
| $\nabla$ | nabla | 梯度算子 | $\nabla_\theta L$ 表示对参数求梯度 |
| $\mathbb{E}$ | 期望 E | 期望值 | 无手算可能，按降级规则处理 |
| $\mathbb{R}^{n}$ | R n 维 | n 维实数向量空间 | 张量维度说明用 |
| $\|\cdot\|_2$ | L2 范数 | 欧氏长度 | $\|x\|_2^2=\sum x_i^2$，手算只需两项 |
| $\|\cdot\|_1$ | L1 范数 | 绝对值之和 | 稀疏正则用它 |
| $\odot$ | Hadamard 积 | 逐元素相乘 | 门控机制的标准写法 |
| $\otimes$ | 卷积 / 张量积 | 卷积运算（也写作 $*$） | 与乘号区分，别混 |
| $\top$ | 转置 | $A^\top$ | 与外积、内积公式配套 |
| $:=$ / $\leftarrow$ | 定义为 / 赋值为 | 更新式 | $\theta \leftarrow \theta - \eta\nabla L$ |
| $\propto$ | 正比于 | 比例关系 | 归一化前常出现 |
| $\approx$ | 约等于 | 近似 | 近似处要说明忽略了多少 |
| $\sim$ | 服从 | $x\sim\mathcal{N}(\mu,\sigma^2)$ | 分布假设的写法 |
| $\mathcal{O}(\cdot)$ | 复杂度 | 计算量阶数 | 报复杂度时用 |
| $\arg\max$ / $\arg\min$ | arg max / arg min | 使函数取最大/最小的自变量 | 分类决策 $\hat y=\arg\max_k p_k$ |
| $[\cdot]^+$ | 正部 | $\max(0,\cdot)$ | 合页损失的标准写法 |
| $\mathbb{1}\{\cdot\}$ | 指示函数 | 条件成立为 1，否则 0 | 分类正确率公式里常见 |
| $\log$ / $\ln$ | 对数 | 信息论里通常指自然对数 | 交叉熵 $-\ln p$ 要对齐底数 |
| $\exp(\cdot)$ | 指数 | $e^{(\cdot)}$ | Softmax 的分子 |
| $!$ | 阶乘 | 排列组合 | 组合数 $C_n^k$ 常见 |
| $\infty$ | 无穷 | 极限 | 讲收敛时出现 |
| $\Delta$ | 大写 delta | 增量 / 差值 | $\Delta f=f_s/N$ 频率分辨率 |
| $\epsilon$ / $\varepsilon$ | epsilon | 小常数 / 容差 | 防除零、松弛变量 |
| $\rho$ | rho | 相关系数 / 密度 | 互相关公式里常见 |
| $\phi$ / $\varphi$ | phi | 映射函数 / 核函数 | 特征映射 $\phi(x)$ |
| $\psi$ | psi | 小波基函数 / 势函数 | 小波变换里出现 |
| $\Omega$ | 大写 omega | 参数空间 / 集合 | 模型族记号 |

## 三、单位与量纲提醒

- 加速度常用 $g$（$1g\approx9.81\,\mathrm{m/s^2}$）或 $\mathrm{m/s^2}$；论文混用时要统一。
- 频率单位 Hz = 1/s；角频率 rad/s 与 Hz 差 $2\pi$，是最常见的量纲事故。
- dB 是相对量，必须说清参考值（如 $20\lg(V/V_0)$，$V_0=1\,\mu\mathrm{V}$）。
- RUL 的单位是"时间/循环次数"，报误差时要带单位，否则 MAE=3 到底是 3 小时还是 3 天说不清。
