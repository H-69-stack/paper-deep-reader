# 术语分册：电机故障诊断

> 电机是带电摩擦副的另一端：它既是驱动源，也是最常被诊断的对象。这册按"从电磁到机械"的顺序组织：转差率与转频 → 定子/转子故障 → 气隙与偏心 → 供电与轴承电流。
> 每行 = 术语 | 一句话定义 | 生活化比喻 | 信号里怎么体现。

| 术语 | 一句话定义 | 生活化比喻 | 信号里怎么体现 |
|---|---|---|---|
| 异步电机 / 感应电机 | 转子电流由定子磁场感应产生的交流电机 | 隔空推着转的转盘 | 结构简单、最常用于工业驱动 |
| 极对数 p | 定子绕组形成的磁极对数量 | 磁场的"扇叶"数 | 决定同步转速，是算转频的第一步 |
| 同步转速 ns | 旋转磁场转速 `ns = 60f/p` | 指挥棒的速度 | 50 Hz、2 对极 → 1500 rpm |
| 转差率 s | 转子比磁场慢的比例 `s = (ns − n)/ns` | 追不上但一直追 | 空载小、满载大，典型 1%–5% |
| 转频 fr | 转子实际转动频率 `fr = n/60` | 心跳 | 所有机械故障特征频率的基准 |
| 转差频率 sf | 转子电流相对定子的频率 | 追不上时"慢下来的节拍" | 断条、偏心的故障频率都以它为单位 |
| 鼠笼转子 | 由导条与端环短路的转子结构 | 笼子里的金属条 | 导条断裂是最典型的转子故障 |
| 断条（Broken Bar） | 转子导条断裂，该槽失去电流 | 笼子断了一根栏杆 | 定子电流出现 `(1 ± 2ks)f` 边带，k=1,2,… |
| 端环断裂 | 短接导条的端环开裂 | 笼子两端的箍断了 | 与断条类似，但边带更多、更宽 |
| 定子绕组匝间短路 | 同一相内相邻匝绝缘破坏而短接 | 弹簧几圈粘一起 | 该相电流增大、三相不平衡、局部温升 |
| 绝缘电阻 | 绕组对地/相间的绝缘能力 | 电线皮破没破 | 下降是早期征兆，需要离线或专用监测 |
| 三相不平衡 | 三相电流/电压幅值或相位不对称 | 三条腿不一样长 | 负序分量上升，可引起过热与振动 |
| 静态偏心 | 转子中心相对定子中心有固定偏移 | 轴装歪了 | 气隙不均，产生 `(1 ± k)f` 或极通过频率 |
| 动态偏心 | 转子中心随转动周期变化 | 轴在转的时候晃 | 出现转频调制的边带，振动谱更"脏" |
| 气隙偏心 | 上述两种的统一叫法 | 轮胎没装正 | 电流与振动同时出现特征边带 |
| MCSA（电机电流特征分析） | 从定子电流谱里读故障特征 | 从"耗电曲线"看病 | 不需额外传感器，但要求高采样率与长记录 |
| Park 矢量 | 把三相电流变换成两相正交分量 | 把三个方向的力合成一个箭头 | 故障时矢量轨迹由圆变椭圆/出现缺口 |
| 起动电流 | 直接起动瞬间的大电流 | 起步时猛踩油门 | 可达额定 5–8 倍，是诊断的天然激励 |
| 起动瞬态诊断 | 利用起动过程做诊断 | 用"起跑"看腿脚 | 起动时滑差从 1 扫到稳态，边带扫频更易识别 |
| 负载率 | 实际输出与额定功率之比 | 挑多重 | 过低时故障特征弱，过高时热故障多 |
| 效率 / 功率因数 | 输出机械功率与输入电功率之比 / 有功与视在之比 | 干活效率 / 用不用力 | 下降说明损耗增加（绕组、铁耗、摩擦） |
| 温升与绝缘等级 | 绕组温升限值按绝缘等级（B/F/H）分级 | 耐热等级 | 长期超温使绝缘寿命按 10℃ 减半（经验规则） |
| VFD / 变频器 | 用变频调速的驱动装置 | 可调转速的油门 | 引入开关谐波与轴电压，是轴承电流的主因 |
| 开关谐波 | 变频器 PWM 产生的高频成分 | 油门踩得一顿一顿 | 电流谱出现开关频率及其边带，干扰诊断 |
| 轴电压 / 轴承电流 | 转轴与外壳间的电位差导致电流经轴承放电 | 轴承里打微型闪电 | 滚道出现电蚀凹坑（搓衣板纹），早期包络谱异常 |
| 接地碳刷 | 把轴电流引走、保护轴承的部件 | 给静电装个地线 | 缺失或磨损时轴承电蚀风险显著上升 |
| 机械特征频率 | 由轴承、齿轮、联轴器决定的振动频率 | 各零件的"嗓门" | 与电磁特征频率可能重叠，需要交叉验证 |
| 转频估计 | 从电流/振动中估计真实转速 | 数脉搏 | 可用电流基频、编码器或振动谐波间距 |
| 转矩脉动 | 输出转矩的周期性波动 | 推车时一顿一顿 | 6 倍基频（6f）常见于三相电机 |
| 齿槽转矩 | 定转子齿槽对齐引起的转矩波动 | 磁铁一格一格吸 | 低速时明显，与极槽配合有关 |
| 冷却与风路 | 风扇/水冷对温升的影响 | 出汗散热 | 风路堵塞 → 温升异常，易误判为电气故障 |
| 直流电机换向器与电刷 | 靠换向器与电刷实现机械换向 | 老式电钻的火花 | 火花等级、电刷磨损、换向器椭圆度是主要诊断量 |
| 电机故障诊断的三路信号 | 电流（电磁）、振动（机械）、温度（热） | 三张化验单一起看 | 只用电流会漏机械故障，只用振动会漏匝间短路 |

## 数字例子：从电网频率算到断条边带

设电网 $f = 50$ Hz，极对数 $p = 2$，满载转差率 $s = 0.04$。

- 同步转速：$n_s = 60f/p = 60 \times 50 / 2 = 1500$ rpm
- 实际转速：$n = n_s(1 - s) = 1500 \times 0.96 = 1440$ rpm
- 转频：$f_r = n/60 = 24$ Hz
- 断条边带（k=1）：$f(1 \pm 2s) = 50 \times (1 \pm 0.08) = 54$ Hz 与 $46$ Hz

**读法**：基频 50 Hz 两侧各偏移 4 Hz 出现一对边带，就是断条的典型指纹。注意**边带间距是 2sf 而不是 sf**，这是最容易记错的地方；另外边带幅值通常只有基频的百分之几，必须做谱平均或高分辨率 FFT 才看得清。
