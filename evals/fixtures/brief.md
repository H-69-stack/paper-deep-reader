# 速览：多尺度残差网络与域自适应的变工况轴承故障诊断

> `evals/` 用的速览模式样本，约 800 字，对应模板第十节。

## 一句话总览

用三个尺度的卷积把振动特征拼起来，再用域自适应抹平转速与负载带来的分布差异，让轴承诊断在换工况时少掉点。

## 要点

| 项 | 内容 |
|---|---|
| 方法一句话 | 三种窗口大小的卷积并行提特征后拼接，再接一个域判别器做对抗训练 |
| 数据 | 两个公开轴承数据集，每个故障类约 200 段振动信号，采样率 12kHz |
| 关键设置 | 学习率 1e-3、批大小 64、训练 100 轮，分类损失与域判别损失交替更新 |
| 指标 | 同工况准确率 98.2%，跨工况 92.7% |
| 主要结论 | 相对基线 DANN 提升 3.2 个百分点；去掉多尺度拼接后掉到 88.1%，说明拼接是主要贡献 |
| 最大局限 | 只做了轴承数据，没有液压系统的实验；判别器权重靠人工调，缺少理论指导 |

## 值不值得细读

如果你的研究方向是振动信号的跨工况迁移，这篇值得细读第 3 节和第 5 节。方法本身不新，多尺度卷积和域判别都是现成积木，但它把两者放进同一个训练回路，消融做得干净，能看清每个部件各贡献多少。

如果你关心的是液压阀的耦合故障，这篇只能借框架、不能借结论。它的输入是单通道振动，你的场景是压力加电流的多通道耦合信号，通道对齐和采样率都不一样，直接搬会失效。重点只看第 7 节关于迁移代价的讨论，其余可以跳过。

如果你只是想确认"域自适应在故障诊断里现在能做到什么水平"，看完上面那张表就够了，不必读正文：92.7% 的跨工况准确率大概就是这个方向当前的常见水位。

## 不适合细读的情况

需要理论保证的读者可以跳过，论文没有任何收敛性或误差界分析。想要模块级复现代码的读者也要注意，论文只给了结构图，没有开源，训练细节里判别器的更新间隔没有写清楚。
